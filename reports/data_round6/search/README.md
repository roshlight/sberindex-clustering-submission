# Серверный поиск: шестой раунд

Запуск `data-round6-20260916-01` выполнен через установленный SearXNG на сервере. Серверные конфигурации — `configs/data_round6_needs.json` и `configs/data_round6_sources.json`: четыре исследовательских вопроса, 20 запросов, по две страницы результатов. Их содержимое сохранено в корпусе запуска как `data_needs.json` и `source_catalog.json`. Активным выбран доступный движок `google cse`.

План из 40 запросов не выполнен полностью: два фактических запроса получили ограниченные ответы, 38 отложены; строк поисковой выдачи — 0. Продолжение по четырём заранее заданным официальным страницам и ограниченному обходу ссылок дало 15 документов-кандидатов: 13 тел скачаны, две загрузки завершились сетевой ошибкой. Среди загруженных есть общие документы навигации; число загрузок не означает число пригодных наборов данных. Региональные страницы затем удалось получить локально через curl с проверкой TLS, что отражено в отдельной ветке economy.

Для трёх карточек и одной критической проверки использована только запрошенная модель **`deepseek/deepseek-v4-pro-0813`**. Выполнено четыре вызова, стоимость по ответам провайдера **0.09180249359999999 USD**, 70252 входных и 24324 выходных токена. Карточки не являются численным доказательством и не использованы вместо чтения исходников.

Серверный корпус содержит 121 файл. Проверены SHA всех 120 файлов, перечисленных в серверном манифесте; сам манифест сохранён дополнительно. Переменные окружения с ключами, конфигурация SSH и файлы токенов не экспортировались.

Два машинных результата воспроизводятся прежним неизменённым общим помощником:

```powershell
uv run --project enrichment --frozen --offline python enrichment/scripts/summarize_round5_search.py --raw <raw6>/search --out <NEW>
```

В имени помощника осталось `round5`; он обрабатывает сохранённые манифесты и в этом раунде не менялся. Полный журнал содержит реальные неудачные и отложенные попытки. Исчерпывающим поиском эту серверную выдачу считать нельзя; результат раунда основан также на прямом чтении официальных каталогов.
