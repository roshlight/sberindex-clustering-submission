# Воспроизведение шестого сбора

Владелец поставки — команда `sberindex-hackathon-2026/municipal-economic-profiles`. Дата: 16.09.2026. Исходный коммит до сбора: `3ea23bc0a0caed73df9cbf097ad48cfac6f0ba3c`. Тег поставки: `data-round6-2026-09-16`. Контрольные суммы кода, результатов и документов перечислены в [delivery_manifest.json](delivery_manifest.json).

Повторяется обработка сохранённого снимка. Новое получение веб-страниц, выдачи SearXNG и ответов DeepSeek — отдельный сбор; их неизменность не обещается. Ручное чтение документов и заключения рецензентов также не становятся автоматическими от совпадения файлов.

## Окружение

Нужны Git, Python 3.12, `uv` и доступ команды к частному GitHub через `gh`. Зависимости закреплены в `enrichment/uv.lock`. Для повторения таблиц не нужны ключи OpenRouter, Telegram, доступ к серверу или Microsoft Word. Word использовался для первичной конвертации DOC; оригиналы и закреплённые результаты этой конвертации включены в архивы.

Для архивов, распаковки и повторного результата предусмотрите около 1 ГБ свободного места сверх Python-окружения. Это ориентир, не измеренный максимум. GPU не требуется. Большие архивы МСП прежних раундов дополнительно скачивать не нужно: два повторно использованных исторических классификатора включены в поставку географии.

В новом рабочем каталоге:

```powershell
New-Item -ItemType Directory outputs
gh repo clone sberindex-hackathon-2026/municipal-economic-profiles outputs/municipal-economic-profiles
Set-Location outputs/municipal-economic-profiles
git switch --detach data-round6-2026-09-16
uv sync --project enrichment --frozen
New-Item -ItemType Directory -Force ../../work/round6-download
gh release download data-round6-2026-09-16 --pattern '*.zip' --pattern SHA256SUMS.txt --dir ../../work/round6-download
uv run --project enrichment --frozen --offline python enrichment/scripts/verify_round6_delivery.py --repo . --release-dir ../../work/round6-download
```

Проверяющий скрипт сверяет скачанные файлы с закреплёнными в репозитории SHA, а не только с соседним скачанным текстовым списком. После успешной проверки распакуйте пять ZIP в новый каталог:

```powershell
New-Item -ItemType Directory ../../work/round6-unpacked
Get-ChildItem -LiteralPath ../../work/round6-download -Filter '*.zip' | ForEach-Object {
    Expand-Archive -LiteralPath $_.FullName -DestinationPath ../../work/round6-unpacked
}
```

Внутри ZIP сохранён префикс `raw6/<ветвь>`; не убирайте его. Каждый архив содержит отдельный `MANIFEST.data-round6-<ветвь>.json`. Ветка `search` содержит серверный запуск целиком. В `geography/prior-geography/reused` находятся два неизменённых исторических CSV из пятого раунда.

## Единый повтор

Из корня репозитория:

```powershell
uv run --project enrichment --frozen --offline python enrichment/scripts/replay_round6.py --repo . --raw ../../work/round6-unpacked/raw6 --prior-geography-raw ../../work/round6-unpacked/raw6/geography/prior-geography --output ../../work/round6-independent-replay
```

Каталог результата должен быть новым, вне репозитория и входных каталогов. Повтор запускает пять ветвей, проверяет входные SHA, сравнивает машинные результаты и сохраняет журналы. Несовпадение или ошибка шага прерывает повтор; результат и диагностика остаются в `QA.json` и логах. Ручные пояснения, рецепты и отдельные заключения перечислены как невоспроизводимые автоматически документы.

| Ветвь | Что повторяется |
|---|---|
| Экономика | Извлечение 276 денежных значений, 66 описаний документов, 33 сопоставлений PDF/DOCX и двух региональных остатков |
| МСП | Проверка исходного инвентаря, выбранного XML, дат работников, кода и геосправочников автора |
| География | Чтение шести CSV переходов, исторических классификаторов и документов; кандидаты остаются кандидатами |
| Объекты | Извлечение текста и ячеек по сохранённому рецепту, проверка лет, единиц, строк и сумм |
| Поиск | Проверка серверных хешей и счётчиков сохранённого запуска |

Отдельные команды и определения показателей приведены в README каждой ветви. [Economy](economy/README.md) также содержит команды повторной распаковки оригинальных архивов и новой конвертации Word. Переработка сохранённых PDF/DOCX повторяется побайтно; новая конвертация Word может менять внутренние метаданные и требует новой проверки.

## Проверки и обновления

```powershell
uv run --project enrichment --frozen --offline pytest enrichment/tests -q
uv run --project enrichment --frozen --offline ruff check enrichment
uv run --project enrichment --frozen --offline ruff format --check enrichment
```

Состояние выполненных проверок — в [QA.md](QA.md). Полный повтор новым получателем в чистом окружении ещё не выполнялся. Локальное воспроизведение сделано в существующем закреплённом окружении Windows.

Архивы собираются по явным спискам [delivery/](delivery/). Упаковщик проверяет пути, известные шаблоны секретов, CRC ZIP и SHA каждого включённого файла. Побайтовое совпадение повторно собранного ZIP не обещается из-за метаданных времени; проверяемый договор — состав и байты его содержимого. Две точные копии публичного PDF содержат похожий на токен фрагмент служебной JPEG-таблицы; узкое проверенное исключение описано в протоколе упаковки, остальные совпадения блокируются.

Для дальнейшего сетевого сбора используйте новые каталоги. Изменение SHA означает новую версию источника и требует нового разбора; не заменяйте ожидаемые хеши прежней поставки. Основные панели, маски, графы и модели этим сбором не менялись. Историческая география МСП, охват региональных показателей и статистическое отражение расходов Черского остаются предметом проверки.
