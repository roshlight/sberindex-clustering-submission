# История кодов населённых пунктов: шестой раунд сбора

Получены официальные переходы между аннулированными и действующими кодами ОКТМО. Они позволяют составить проверяемые варианты исторической принадлежности населённых пунктов, но ещё не устанавливают адрес предприятия на дату наблюдения. **Историческое присоединение МСП к панели остаётся `unknown`; разрешённых присоединений — 0, `model_adoption=false`.**

Основной новый источник — [перекодировочная таблица Росстата](https://rosstat.gov.ru/opendata/7708234640-codingtable). Сохранены шесть её версий: 20.12.2023, 01.01.2024, 02.11.2024, 08.01.2025, 01.06.2026 и 01.09.2026. Для кандидатов используется версия 01.06.2026, соседняя с версией МСП `v20260605`. Дата файла обозначает выпуск таблицы; отдельного поля даты вступления перехода в силу в CSV нет.

Июньская таблица содержит 81 292 строки: 80 565 полных пар кодов, 692 строки с пустым назначением и 35 строк с нестандартным назначением. В исходных строках сохранены пробелы и пустые значения. Для сравнения удаляются только пробелы-разделители, включая неразрывные; коды не дополняются нулями. Восемь повторных исходных строк относятся к неполным переходам и сохранены в `transition_nonlinks.csv`; проверка повторов полных пар в `transition_duplicate_rows.csv` не выявила строк. Среди полных переходов 98 рёбер имеют неединственное прямое или обратное соответствие. Их нельзя превращать в однозначный справочник замен.

В [официальном разделе классификаторов](https://rosstat.gov.ru/classification) дополнительно скачаны документы изменений для приоритетных регионов. **Все 119 пар изменения 643/2023 для Приморья независимо совпали между DOCX и CSV.** Остальные 13 файлов DOC сохранены как первичные документы, но их содержимое программно не извлекалось. В пермском двухстраничном перечне с датой 01.01.2024 в имени найдено 42 из 42 кодов муниципалитетов нашей панели. Документ содержит раздел 1 и указывает вступление учтённого изменения в силу 01.11.2023; перечня населённых пунктов в нём нет.

## Какие кандидаты сформированы

Введение к ОКТМО описывает построение кода населённого пункта из восьмизначного кода муниципального образования и трёх дополнительных знаков. Кандидат принимается только при наличии соответствующей записи раздела 1 классификатора и точного кода в панели. Использованы неизменённые версии классификатора 08.02.2023 и 25.01.2024 из пятого раунда. Все 2016 кодов панели найдены в каждом соответствующем выпуске; это проверка наличия кодов, а не юридических границ.

`priority_settlement_parent_candidates.csv` содержит 9736 записей для Перми, Приморья и Саха. Издание введения относится к 2026 году. Сами исторические CSV могут включать записи, вводимые после даты выпуска; поэтому сохранены дата введения, версия справочника и флаг `record_date_after_reference`. Совпадение этих записей не объявляется готовым снимком на 1 января.

`candidate_transitions_to_panel.csv` связывает только явный одношаговый переход, старый код населённого пункта в историческом справочнике и код из годового файла МСП. Транзитивные цепочки и совпадения по похожему названию не применяются. Получено 2016 строк-кандидатов — это число рёбер, совпавшее с размером исходной муниципальной панели лишь численно.

| Год | Регион | Групп исходных кодов | Строк МСП с этими кодами | Возможных МО панели |
|---|---|---:|---:|---:|
| 2023 | Пермский край | 760 | 25 774 | 21 |
| 2023 | Приморский край | 282 | 12 488 | 14 |
| 2024 | Пермский край | 776 | 26 739 | 21 |
| 2024 | Приморский край | 182 | 9 985 | 9 |

Строки МСП посчитаны один раз на исходный код внутри года, даже при нескольких рёбрах. Это размер очереди на проверку, не прирост подтверждённого покрытия и не число уникальных предприятий. У трёх пермских кодов в каждом году имеется несколько предшественников в общей таблице переходов. Для Саха в июньском файле нет строк перекодировки; это не доказательство отсутствия территориальных изменений.

## Что подтверждено по ГАР

Скачаны [официальный паспорт ФНС](https://www.nalog.gov.ru/opendata/7707329152-fias/), текущий каталог выгрузок и два архива XSD. В муниципальной иерархии описаны `PARENTOBJID`, `OKTMO`, `STARTDATE`, `ENDDATE`, `PREVID`, `NEXTID`, отдельно — `UPDATEDATE`. Это подтверждает наличие структуры для проверки истории. Каталог API, полученный в этом раунде, содержит 65 версий от 03.02.2026 до 15.09.2026. Исторические записи объектов ГАР за 2023/2024 не получены; полные базы ГАР не скачивались. Отсутствие старых версий в ответе API не доказывает, что архивов вообще нет.

Для принятия муниципального ключа ещё нужны датированный адрес конкретной записи МСП, проверенное соответствие адресного объекта и населённого пункта, дата действия перехода и проверка принадлежности на нужную дату. Юридическая эквивалентность границ не следует из равенства кодов. Происхождение геокодирования годового набора МСП этим раундом не установлено.

## Воспроизведение и происхождение

`downloaded_sources.csv` содержит URL, время, размер и SHA-256 всех 33 полученных тел ответов. Сохранены также шесть неудачных попыток: локальные сетевые ошибки, отсутствующий `/Updates` и первоначальные URL с неэкранированными пробелами. Последние два документа успешно получены по корректно кодированным URL. Успешные загрузки выполнены с проверкой TLS через настроенный сервер. Старые данные и маски панели не изменялись.

`manifest.json` фиксирует сырые и повторно использованные входы, скрипт и машинные выходы. `evidence_ledger.csv` разделяет доказанные свойства источника и оставшиеся ограничения. Для чтения DOC не добавлялись зависимости; PDF, DOCX и XSD разбираются имеющимися библиотеками.

Из корня репозитория, в новый каталог:

```powershell
enrichment/.venv/Scripts/python.exe enrichment/scripts/audit_round6_geography.py --repo . --raw ../../work/data-round6/geography --prior-raw ../../work/data-round5/geography --out work/round6-geography-replay
enrichment/.venv/Scripts/python.exe -m pytest enrichment/tests/test_round6_geography.py -q
```

Replay работает без сети и без импорта производственных расчётов предыдущих раундов. Тесты проверяют ведущий ноль, пропуски назначения, сохранение повторов, неожиданные поля и обязательное наличие родителя в классификаторе. README — отдельное пояснение; численные машинные результаты воспроизводит команда выше. Новая загрузка выполняется `collect_round6_geography.py --out <новый каталог> --sources <JSON имя_файла:URL>`; переменная `PUBLIC_CA_BUNDLES_JSON` при необходимости задаёт путь к карте публичных сертификатов.
