# Зарплата, занятость и источники муниципальной экономики

Получены и проверены **8030 числовых значений из 8064 ожидаемых** для двух годовых признаков основной панели из 2016 муниципалитетов. Это описательный кандидатный слой с условием о географии; исходная кластеризация и предыдущие результаты не менялись.

| Год | Показатель | Число | Явный маркер источника | Строка не принята или не возвращена | Ожидалось |
|---|---|---:|---:|---:|---:|
| 2023 | `8423005`, среднесписочная численность | 2015 | 0 | 1 | 2016 |
| 2023 | `8423007`, среднемесячная зарплата | 2015 | 0 | 1 | 2016 |
| 2024 | `8423005`, среднесписочная численность | 2000 | 1 | 15 | 2016 |
| 2024 | `8423007`, среднемесячная зарплата | 2000 | 1 | 15 | 2016 |

Оба показателя относятся к организациям **без субъектов малого предпринимательства**, годовой период `79` — январь–декабрь, агрегат ОКВЭД2 `101` — всего по обследуемым видам деятельности. Численность измерена в людях, зарплата — в рублях за месяц. Это не число всех занятых жителей и не располагаемый доход населения.

## Файлы

- `annual_candidates/annual_candidate_panel.parquet` и CSV: 8064 строки с кодовыми связями, исходными значениями, статусами, SHA и флагами географии. Для анализа предпочтителен Parquet: строковые коды и точное десятичное представление не зависят от автопреобразования Excel.
- `annual_candidates/annual_coverage.csv`, `annual_gaps.csv`, `summary.json`: покрытие, все 34 пробела и контрольные суммы.
- `source/economy_source.parquet` и CSV: 8082 принятые исходные ячейки по кодам источника, из них 8030 числовых и 52 явных пустых/специальных маркера. Разница с годовой панелью возникает потому, что для старых и новых кодов запрашивались оба года, а присоединяется только код соответствующей годовой версии.
- `source/annual_code_reference_links.csv`: 4032 годовые кодовые связи; `source/target_status.csv`: 4188 статусов пар «код × показатель».
- `source_cell_qa.json`: все 8082 ячейки сверены с физическими строками, колонками годов и payload сохранённых CSV; 142 уникальных принятых CSV-ответа. Хэши выгрузок и снимка реализации проверены.
- `source_capture_inventory.json`: 286 первичных HTTP-ответов с URL, POST payload, временем получения и SHA. Их исходные байты находятся в raw-поставке.
- `pilot_source_cells.csv`, `form_inventory.csv`, `pilot_summary.json`: 22 формы и 15 реальных CSV-экспортов по расширенному набору показателей, 224 ячейки, 212 чисел. Это ограниченные пилоты, отдельно от массовой панели.
- `inventory.json` и [SOURCE_GUIDE.md](SOURCE_GUIDE.md): назначение признаков, определения, первичные источники и ограничения дальнейшего сбора. `sources_manifest.json` описывает дополнительные скачанные источники и проверки доступности.

`value` хранится строкой с точной десятичной записью исходного числа. `value_raw` сохраняет исходную ячейку. Ноль остаётся нулём; пустота и иные специальные символы не становятся нулём. `source_unit_label` сохраняет буквальное написание единицы; `unit` использует явное эквивалентное обозначение «рубль» для «рубль»/«рублей» без изменения числового масштаба. Отсутствие даты первоначальной публикации представлено `published_at=NULL`.

## Оставшиеся пробелы

Для `28714000`, территория СберИндекса `2710`, оба года и оба показателя оставлены на проверку: форма содержит усечённую муниципальную подпись, CSV — полную. Совпадение префикса не принято как доказательство атрибуции. Четыре муниципалитета Липецкой области (`1412`, `1416`, `1420`, `1425`) вернули только 2023 год. Десять кодов муниципальных округов Ставропольского края не вернули 2024 год (`810`, `811`, `814`, `815`, `817`, `819`, `821`, `822`, `823`, `825`). Старые коды для этих ячеек автоматически не подставлялись. Для территории `229`, кода `87725000`, источник вернул в 2024 году по обоим показателям пустую ячейку. Все случаи перечислены в `annual_gaps.csv`.

Годовая связь использует точный код и срез справочника на 1 января. Она не подтверждает неизменность границ или состава наблюдаемых организаций за весь год. Исходные шесть флагов `temporal_review_required` сохранены; решения, принятые ранее для даты населения, здесь автоматически не распространяются на годовой экономический показатель.

## Проверки и история

В первом завершённом проходе `full-v1` сделано 263 HTTP-запроса. Он дал 6996 принятых ячеек, включая 6960 чисел. Его данные, манифест и снимок кода сохранены. Затем `full-v2` повторно использовал 261 ответ из кэша и сделал 23 новых запроса для ранее не выгруженных форм и безопасно разделённых пакетов. **2094 кодовых цели не означают 2094 HTTP-запроса.** Ограничение нагрузки — не менее 2,5 секунды между сетевыми запросами этого клиента; 403/429/5xx обрабатываются ограниченной политикой остановки и повторов.

В v2 семантическая проверка кодированных агрегата и периода допускает регистр букв (`casefold`) и только подтверждённые варианты: аннотацию `(101.АГ)`, «за январь-декабрь» и единицу «рублей». Полная подпись из фактической формы затем сохраняется; контекст CSV должен совпасть с ней буквально после нормализации пробелов. Строки заголовка могут объединяться лишь до явной строки годов, после чего проверяется полный контекст индикатора, агрегата и периода. Это не общий нечёткий разбор текста. Усечённые подписи изолируются в одиночный запрос и всё равно не принимаются по префиксу.

17 локальных и серверных тестов этой части прошли; Ruff check/format для её файлов прошли. Тесты проверяют, в частности, смещение пустых колонок, неправильные периоды и единицы, чужие подписи, дубликаты, переносы и точки с запятой внутри названий, сохранение результатов перед сетевой остановкой, смену кода между годами и различие нуля, пропуска и отсутствующей строки. Итоговый общий тестовый прогон репозитория фиксируется в корневом отчёте поставки.

## Воспроизведение без новой сети

Команды выполняются из `enrichment/` после установки независимого окружения `uv sync --frozen`. Нужно распаковать серверную raw-поставку так, чтобы в корне репозитория появился `work/enrichment-v3/economy/cache/`; исходные ответы и metadata должны оставаться вместе. Если архив распакован иначе, измените только соответствующий путь `--cache`. Предыдущие output-каталоги не перезаписываются.

```sh
uv run --frozen python scripts/run_economy_bulk.py --targets ../reports/enrichment_v2/code_bridge/population_fetch_candidate_targets.json --output ../work/economy-replay-v2 --cache ../work/enrichment-v3/economy/cache --cache-only --interval 2.5 --batch-size 100
uv run --frozen python scripts/verify_economy_bulk.py --directory ../work/economy-replay-v2 --cache ../work/enrichment-v3/economy/cache
uv run --frozen python scripts/summarize_economy_bulk.py --directory ../work/economy-replay-v2 --output ../work/economy-annual-replay-v2
uv run --frozen pytest -q tests/test_economy_bulk.py tests/test_economy_candidate_panel.py
uv run --frozen ruff check src/sber_enrichment/economy_bulk.py scripts/run_economy_bulk.py scripts/verify_economy_bulk.py scripts/summarize_economy_bulk.py tests/test_economy_bulk.py tests/test_economy_candidate_panel.py
```

Для свежего сетевого сбора уберите `--cache-only`, используйте новый каталог output и, на сервере, `--ca-bundle /home/vpnadmin/services/sberindex-enrichment/certs/russian-trusted.pem`. Это публичная цепочка доверия, не секретный ключ; TLS-проверка не отключается. Источник может пересмотреть данные, поэтому такой запуск не гарантирует повторения чисел снимка сентября 2026 года.

Повторная обработка создаёт новые время запуска, путь и режим в manifest. Байтовая идентичность всех служебных файлов между платформами не заявляется. Исторические SHA относятся к сохранённым байтам; для нового запуска проверяются его собственные SHA и равенство содержательных ключей и ячеек. Пакет воспроизводит извлечение и кодовую кандидатную панель при наличии raw-архива; он не воспроизводит независимый правовой аудит границ, свежую публикацию Росстата или новый модельный эксперимент.
