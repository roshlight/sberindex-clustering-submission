# Повторение извлечения и проверок

Этот пакет воспроизводит извлечение сохранённых значений и документирует условия их соединения. Он не содержит нового результата кластеризации. Исходный эксперимент и версии обогащения v1/v2 остаются неизменными.

## Получение снимков

Из [приватного выпуска context-data-2026-09-15](https://github.com/sberindex-hackathon-2026/municipal-economic-profiles/releases/tag/context-data-2026-09-15) скачать три ZIP, `archives_manifest.json` и `SHA256SUMS.txt`. Доступ требует членства в репозитории. SHA-256 каждого ZIP должен совпасть с манифестом; каталоги всех вложенных файлов находятся также в `data/releases/context-2026-09-15/`.

- `server-discovery-snapshots.zip`: девять оригинальных архивов БДМО, фильтрованные Parquet, метаданные, серверный разбор источников и его снимок кода.
- `server-economy-snapshots.zip`: первичные формы и CSV, HTTP-кэш, обе версии массового сбора экономики, результаты, параметры и снимки реализации.
- `local-context-snapshots.zip`: бюллетени и региональная демография, цены, правовые и научные документы, пространственные ответы, экономические пилоты, метаданные и исследовательские скрипты.

ZIP содержат относительные пути. Не распаковывать поверх существующего рабочего сбора. Для полного повторения исследовательских скриптов удобно сохранить исходную структуру: новый каталог рабочего пространства, в нём `outputs/municipal-economic-profiles/` с клоном репозитория и `work/` из архивов. Серверный архив дополнительно содержит `enrichment/runs/` как исторические данные, не как действующий сервис. Скрипты получения данных могут содержать исходные машинные пути; их необходимо настроить для нового запуска. Секреты и окружение сервиса в поставку не включены.

Установить зависимости из `enrichment/` командой `uv sync --frozen`. Существующий `uv.lock` не менялся. Проверка этой поставки выполнялась в уже установленном окружении Python 3.12.10 на Windows и на сервере; отдельное чистое развёртывание окружения с нуля не выполнялось.

## Экономика: проверенный повторный запуск без сети

Из каталога `enrichment/` выполнить команды, подставив абсолютные пути к распакованному кэшу и новым выходным каталогам:

```text
uv run --frozen python scripts/run_economy_bulk.py --targets-path ../reports/enrichment_v2/code_bridge/population_fetch_candidate_targets.json --output <новый-source-output> --cache <распакованный-work/enrichment-v3/economy/cache> --cache-only --interval 2.5 --batch-size 100
uv run --frozen python scripts/verify_economy_bulk.py --directory <новый-source-output> --cache <распакованный-work/enrichment-v3/economy/cache>
uv run --frozen python scripts/summarize_economy_bulk.py --directory <новый-source-output> --output <новый-annual-output>
```

Параметр `--cache-only` запрещает новые сетевые обращения. В проверочном запуске получены 284 попадания в кэш и 0 HTTP-запросов. Все 8082 исходные ячейки, 4032 годовые ссылки, 8064 строки кандидатной панели и таблица покрытия совпали с поставкой по всем колонкам и значениям. Сравнивать таблицы следует с сохранением строковых кодов и пустых строк, не полагаясь на автоматическое определение типов Excel. [Квитанция повторения](offline_replay_qa.json).

Служебные время/пути/режим запуска могут отличаться. Числа, исходные SHA, годы, параметры, статусы и ограничения территории должны совпасть. Для нового сетевого сбора нужен отдельный output и снятие `--cache-only`; новые ответы не гарантируют совпадения со снимком сентября 2026.

## Цены

Из `enrichment/`:

```text
uv run --frozen python scripts/prepare_prices_context.py --raw <распакованный-work/enrichment-v3/prices> --repo .. --out <новый-price-output>
```

Скрипт проверяет буквальные заголовки годов и базу индекса, читает XLSX, строит явные региональные связи и годовую числовую сверку. Ожидаются 9216 строк ИПЦ, 4032 годовые ссылки, 594 строки городского индекса с сохранёнными пропусками и 1152 строки фиксированного набора. Независимый перечитывающий скрипт находится в архиве `work/enrichment-v3/verify_prices_independent.py`; его исходная топология рабочего пространства должна быть сохранена либо пути настроены явно.

## Вторичная муниципальная статистика

Из каждого из девяти оригинальных ZIP извлечь **только верхнеуровневый файл `.parquet`** в один новый каталог. Не требуется распаковывать многогигабайтные CSV. Для каждого Parquet сверить SHA с `work/enrichment-v3/secondary/profiled/summary.json` из серверного архива. Затем из `enrichment/`:

```text
uv run --frozen python scripts/audit_secondary_context.py --raw <каталог-полных-parquet> --out <новый-secondary-output>
```

Ожидаются девять разделов, восемь с нужными годами, 3 214 192 строки 2023–2024, 3 187 196 числовых значений и 57 различных кодов показателей. Скрипт не соединяет `oktmo` или `oktmo_stable` с основной панелью и не агрегирует дополнительные измерения в признаки. Отдельная сверка восьми первичных ячеек описана в [secondary/primary_spotcheck_README.md](secondary/primary_spotcheck_README.md).

## Демография и пространство

В [демографическом отчёте](demography/REPORT.md) приведён порядок четырёх скриптов подготовки. Они рассчитаны на структуру рабочего пространства `outputs/municipal-economic-profiles` + `work`; исходные XLSX и региональные документы лежат в local ZIP. Повторение должно сохранить 1124 целевые строки, 1122 исходных числа, 2 пропуска и **нулевое число автоматически принятых кодовых соединений**. Файл четырёх условно проверенных значений остаётся отдельным дополнением.

Для пространственного блока сохранены скрипты `prepare_sber_spatial_context.py`, `parse_bdpmo_spatial.py`, `audit_spatial_cells.py`, кодированная форма и версии сетевого сборщика на момент запуска. Пути и повторно используемые входы перечислены в `spatial/file_inventory.json`. Часть этих входов входит в прежние выпуски данных; они не объявлены новыми загрузками. [Пространственная записка](spatial/FINDINGS.md) описывает выбор годов, вложенные дорожные категории, повторные ключи и непривязанные строки.

## Проверки кода и границы результата

Из `enrichment/`:

```text
uv run --frozen pytest -q
uv run --frozen ruff check .
uv run --frozen ruff format --check .
```

В поставке прошли 223 теста и Ruff. Сетевые страницы, поиск и модельные карточки не являются детерминированным воспроизведением: их следует проверять по сохранённым документам и журналам. Привязка кандидатов к юридически сопоставимым территориям, полный аудит вторичного архива и повторение аналитического эксперимента остаются отдельными работами. Их отсутствие не скрывается статусом успешного извлечения.
