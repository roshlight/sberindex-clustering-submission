# Отраслевые доли работников: аудит и шесть описательных примеров

Опубликованные доли характеризуют работников учтённых организаций и пригодны для анализа с ограничениями. Они не описывают отрасли занятости всех жителей и не объясняют потребительские остатки причинно. Анализ исследовательский: 2024 год уже был просмотрен.

## Что измерено

Единица таблицы — МО × календарный год, 2023 или 2024. Числитель — среднесписочная численность работников организаций по опубликованному разделу, показатель БДПМО 8423005; знаменатель — официальный итог 101 того же показателя, МО и года. Это работники организаций без субъектов малого предпринимательства, а не число занятых жителей. Данные могут пересматриваться: сохранены снимки, полученные в 2026 году. Зарплаты 8423007 проходят проверку структуры и кодов; они здесь не суммируются.

[Методология Росстата](https://rosstat.gov.ru/storage/mediabank/bdmo_met2024.docx) и [разъяснения по труду](https://35.rosstat.gov.ru/folder/120693) сохранены в предыдущем пакете. Адреса выгрузок, SHA256 и номера строк сохранены в worker_shares.parquet и example_sector_pairs.csv; снимки форм перечислены в исходном raw_source_inventory.json. Здесь нет новых сетевых запросов.

Ключи 10000, 50000 и другие — внутренние значения опций БДПМО, а не формальные пятизначные коды классов ОКВЭД. Проверенное соответствие широким разделам A–S и U записано в section_dictionary.csv. Все варианты исходных подписей сохранены в source_label_dictionary.csv: сопоставление с формой точное по региону, показателю, коду, подписи и SHA256. Варианты пунктуации, сокращения и опечатки не исправляют исходник. Раздел T не получен. U предложен частью форм, но числовых значений численности по нему нет.

## Покрытие и ограничения

Полная таблица содержит 4032 МО-лет для 2016 МО. Положительный официальный итог доступен в 4017 МО-лет. Для отдельных отраслей превышений над итогом найдено 0; защитное правило исключает такие доли, если они появятся, без обрезания до 1. Сумма раскрытых отраслей превышает итог в 88 МО-лет; она сохранена только как диагностическая сумма. Недостающая до итога величина не называется ни отдельной отраслью, ни экономическим остатком.

В 88 случаях превышение суммы составляет 1–3 работника, максимум отношения — 1.001217039. Такой масштаб совместим с округлением опубликованных средних, но причина по самим ячейкам не установлена. Числа и флаги превышения сохранены.

При недоступной диагностической сумме флаг превышения равен NULL: 19 МО-лет. В 4 из них итог работников есть, но не раскрыто ни одного раздела. Эти случаи не превращены в нулевую отраслевую структуру.

Для анализа связи с потребительскими профилями заранее согласованы восемь признаков: A, B, C, D, H, O, P, Q. Пропуски сохраняются; модельные признаки отсутствия готовит основной анализ. Охват ниже имеет знаменателем все 4032 МО-года, а не только формы, предложившие раздел.

Отсутствие опции в форме, неполученная строка и неразрешённый маркер источника разделены в coverage.csv и worker_shares.parquet. Ни один из этих статусов не заменяется нулём. Только явный опубликованный ноль остаётся числовым нулём.

Флаги core_eligible, conservative_eligible, calendar_review и code_type_changed перенесены из frozen core без пересчёта. Независимая юридическая и геометрическая эквивалентность границ во всём слое остаётся неизвестной. Предыдущая сверка пилота сохранила предупреждение о 22 различиях представления пропуска при совпадении чисел/NULL; этот аудит его не устраняет.

## Шесть заранее выбранных примеров

У всех шести совпадают годовые коды и отсутствуют календарный флаг и флаг смены кода/типа. Это позволяет показать условное сравнение одинаковых кодов, но не заменяет независимую проверку границ. Эти цифры не устанавливают причины потребительских расходов, экономический шок или ошибку данных.

## Воспроизведение

Из корня репозитория:

```powershell
uv run --frozen python scripts/round2_sector_analysis.py --repo . --out work/round2-sector-replay
uv run --frozen pytest tests/test_round2_sector_analysis.py
uv run --frozen ruff check scripts/round2_sector_analysis.py tests/test_round2_sector_analysis.py
```

Указанная папка результата должна быть новой или пустой. Нужны три frozen-входа из manifest.json: годовой Parquet отраслей, activity_options.csv и core_v2/annual_panel.csv; для ссылок также используются FINAL_QA.json и methodology_source_inventory.json. Скрипт читает из core только ключи, названия, старый итог работников и флаги. Потребительские доли, расходы, предсказания и остатки не загружаются. Все вычисления локальные. QA.json отделяет пройденные проверки от ограничений источника.

Для повторной проверки 24 исходных ячеек примеров добавьте `--raw-source-dir <папка work/data-round2/sector из raw release>`. Нужны файлы из raw_source_inventory.json предыдущего пакета. Проверяются SHA256, точная исходная подпись и раздел, номер строки, явный заголовок года и числовая ячейка. Без этого аргумента повторная проверка raw отмечается NOT_RUN; числовые таблицы воспроизводятся из frozen Parquet. Результат текущего запуска — PASS; проверенных ячеек — 24. raw_example_trace_check.csv сохраняет эти локаторы без копирования исходных файлов.
