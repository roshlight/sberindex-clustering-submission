# Проверка пятого раунда анализа

Статус: **ready for independent reproduction — готово к независимому воспроизведению**. Цепочка расчётов повторена в новом каталоге с существующим окружением. Независимый алгоритм проверил результаты; запуска другим исследователем в новом чистом окружении ещё не было.

Проверяемый вывод: 64 дополнения расширили описание 32 муниципалитетов, но не изменили решение о включении денежного блока в основную модель потребительского профиля. Все четыре основных 95% интервала включают ноль; условие принятия не выполнено. Новые источники МСП и документов Черского уточняют ограничения и гипотезы, не доказывая историческое муниципальное соответствие или причину инвестиционного пика.

Интервалы построены по 2000 парным перевыборкам регионов из сохранённых ошибок. Они условны по уже обученным прогнозам, не повторяют всю процедуру обучения и не скорректированы на множественные проверки. Большие локальные изменения для 32 МО относятся к двум региональным группам; отдельного интервала для этого среза нет. Основную спецификацию модели и сети этот анализ не меняет.

Первый независимый аудит остановился на побитовом сравнении вещественных чисел после CSV-повтора. Неудачная попытка сохранена в `independent_data_QA_attempt01.json`; для этого конкретного сравнения применён `rtol=1e-14`. Ключи, маски и прежние исходные числа по-прежнему сверяются точно. Предположение об утраченном ведущем нуле ОКТМО проверено по исходной форме и отвергнуто: строковый код источника сохранён буквально, без произвольного дополнения нулями.

После форматирования файла аудита его манифест был заново построен. Итоговый полный повтор выполнен с окончательными байтами кода; старый receipt не использован как подтверждение нового кода. Исходные данные и результаты моделей при этом не изменились.

Штатная сборка HTML обнаружила известное переполнение заголовка при системной полосе прокрутки Windows. Сохранённый сборщик применил ранее проверенную поправку ширины CSS и повторил штатный браузерный контроль. Payload, runtime и файлы плагина не менялись. Это не проверка всех браузеров или печати.

Корневой `uv.lock` фиксирует Python-зависимости. HTML собран установленным Data Analytics 0.2.10; сборка и её SHA-256 описаны в `portable_delivery.json`. Для расчётов не нужны сетевые сервисы, LLM или секреты. GitHub используется только для получения репозитория и архивов. Команды, допуски и границы воспроизведения — в [REPRODUCE.md](REPRODUCE.md); состав поставки — в `delivery_manifest.json`.
