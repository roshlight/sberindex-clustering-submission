# Дополнительный поиск через DeepSeek V4 Pro

По запросу владельца новый проход использовал только `deepseek/deepseek-v4-pro-0813`: расширение запросов, разбор документов и сопоставление карточек. [Машинный итог](discovery_summary.json) содержит фактические статусы и расход. Числа населения получены отдельным детерминированным загрузчиком БДПМО; модель не заполняла значения и не назначала коды.

Проверен 31 URL: 30 ответили HTTP 200, один завершился сетевой ошибкой. У 26 источников извлечено не менее 300 символов текста. Из 24 выбранных документов получены 22 карточки; одна генерация обрезана, другая обработка завершилась `ValueError`. Общий журнал сохраняет тип ошибки, но не её подробный текст. Архивы и табличные предпросмотры не равнозначны полному разбору числового набора. [Реестр](source_inventory.csv) указывает SHA256 исходника и извлечённого текста, дату получения, тип разбора и усечение.

SearXNG запланировал 66 сочетаний запроса и страницы. Выполнено 10 обращений; два ответа содержали ограничение Google CSE. Оставшиеся 56 отложены после срабатывания общего ограничителя. Снятие денежного лимита OpenRouter не снимает квоту поискового движка. Прямые загрузки известных официальных источников выполнялись отдельно.

Первый запуск `population-deepseek-20260915-01` остановился при расширении запросов: ответ превысил предел 8000 токенов. Его журнал сохранён. Для следующего запуска количество дополнительных запросов ограничено 18, а предел ответа увеличен до 16000. Второй запуск `population-deepseek-20260915-02` завершён. Суммарно API сообщил расход 0.8697871968159998 USD за 27 HTTP-попыток; попыток с неизвестной стоимостью нет. Это сумма сообщённых API значений, а не отдельная сверка счёта.

Карточки и междокументный обзор модели сохранены в серверном архиве как черновики. Они видели только ограниченные тексты выбранных документов и исходный список потребностей. Модельный обзор не учитывает параллельный полный разбор исторических классификаторов и региональные запросы населения, поэтому его вывод о незакрытых потребностях не является итогом этой поставки. Принятые результаты и ограничения находятся в [основном отчёте](../REPORT.md).

Поисковый план сохранён в исходном виде для воспроизведения. Свежесть URL или даты скачивания не доказывает дату действия кода, историческую доступность показателя или эквивалентность границ.
