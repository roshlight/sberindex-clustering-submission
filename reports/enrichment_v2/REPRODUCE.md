# Воспроизведение обогащения населения

Статус поставки: **replayable_with_constraints**. Из сохранённых ответов Росстата можно повторить извлечение населения, проверить исходные ячейки и собрать годовую панель. Независимый полный запуск всего исследовательского и модельного контура из чистого окружения не выполнен. Повторный поиск и обращения к моделям в приведённые команды не входят.

Панель охватывает 2 016 муниципалитетов основного исследования, две даты наблюдения (`2023-01-01`, `2024-01-01`) и два типа населения. Её 8 064 строки включают пробелы. Значения относятся к состоянию на 1 января; скачивание в 2026 году не доказывает, что эти редакции были опубликованы к началу соответствующего года.

## Распаковка и окружение

Релиз `population-data-2026-09-15` содержит два архива. `server-population-snapshots.zip` распакуйте **в корень репозитория** `municipal-economic-profiles`, сохранив относительные пути: после распаковки должен существовать `enrichment/data/bdpmo-mass-cache-20260915-v1/`. Архив `local-source-snapshots.zip` имеет пути относительно рабочего каталога и содержит префиксы `work/` и `outputs/municipal-economic-profiles/`; его распаковывают в отдельный рабочий каталог с такой структурой. Эти два архива имеют разные корни. Не накладывайте архивы на изменённые канонические результаты.

Сначала сверяйте SHA-256 архивов и входных файлов с поставляемыми манифестами. В `data/releases/population-2026-09-15/` находятся `archives_manifest.json`, `server-file-catalog.json`, `local-file-catalog.json` и `verification.json`. Серверный архив содержит 5 864 файла, его размер 46 262 849 байт; локальный содержит 82 файла, размер 134 118 647 байт. Суммарно это 5 946 исходных файлов и 180 381 496 байт архивов. Исходные ответы находятся в архиве; одной копии небольших отчётных таблиц недостаточно для проверки всех ячеек. Индивидуальные `items/` нужны для аудита решений по целям, но повторное извлечение строится из списка целей и сырого кэша.

В четырёх отчётных копиях JSON и соответствующих созданных метаданных серверного архива абсолютный серверный корень заменён на `.`, что отражено исходным и поставочным SHA-256 в `metadata_normalization.json` и каталоге архива: числа, сырые ответы и вложенные хеши выходных таблиц не изменены, исторические хеши относятся к первоначальным манифестам, а каталоги проверяют поставленные байты.

Команды далее выполняются из каталога `enrichment/`. Нужны Python 3.12 и `uv`. Прямые зависимости описаны в `enrichment/pyproject.toml`, точные версии в `enrichment/uv.lock`. Не обновляйте lockfile перед проверкой этой поставки.

```text
uv sync --frozen
```

Если ZIP-файлы помещены в `data/releases/population-2026-09-15/`, проверьте их до распаковки следующей командой из `enrichment/`. Она сверяет также каждый элемент внутри архивов и не исполняет их содержимое.

```text
uv run --frozen python ../scripts/verify_data_release.py ../data/releases/population-2026-09-15
```

Первичное создание окружения может потребовать доступ к репозиторию пакетов. Повторный разбор данных после установки зависимостей не требует ключей OpenRouter, SearXNG, SSH или запросов к Росстату. Публичный российский CA-файл использовался при сетевом сборе на сервере; для режима `--cache-only` он не нужен. Проверка TLS при новом сетевом сборе должна оставаться включённой.

## Повторить извлечение без сети

Каждый запуск пишет в новый каталог. Сохранённые канонические таблицы не перезаписываются.

```text
uv run --frozen python scripts/run_population_bulk.py --targets-path ../reports/enrichment_v2/code_bridge/population_fetch_candidate_targets.json --output data/replay-population-source --cache data/bdpmo-mass-cache-20260915-v1 --interval 1 --batch-size 20 --cache-only
```

`--cache-only` запрещает отправку запроса при отсутствии пригодного сохранённого ответа и при попытке обновления. Пропущенный ответ фиксируется как ошибка, поэтому проверяйте manifest даже при успешном завершении процесса. `complete_with_gaps` означает окончание обработки всех целей с сохранёнными пробелами, а не полное покрытие числами.

В каноническом повторном разборе обработаны 2 094 цели, прочитаны 248 ответов из кэша и выполнено **0 сетевых запросов**. Цель означает уникальную пару `(региональный endpoint, исходный код)`. Число целей нельзя называть числом HTTP-запросов: региональные пакеты объединяют несколько кодов, а при неоднозначном формате используется отдельный запрос.

## Проверить каждую исходную ячейку

```text
uv run --frozen python scripts/verify_population_bulk.py --directory data/replay-population-source --cache data/bdpmo-mass-cache-20260915-v1
```

Проверка сверяет хеши экспортов и снимка кода, уникальность ключа наблюдения, принадлежность кода запросу, тип населения, физическую строку CSV и явную колонку года. Для канонического результата получено `PASS`: 7 157 ячеек, 6 940 числовых значений, 174 отдельных ответа CSV с принятыми ячейками. Отчёт проверки сохранён рядом с полным серверным результатом как `population-bulk-20260915-v3.cell-audit.json`.

## Собрать годовую панель

```text
uv run --frozen python scripts/prepare_population_panel.py --population data/replay-population-source/population_source.csv --reference-links data/replay-population-source/target_reference_links.csv --target-status data/replay-population-source/target_status.csv --cohort ../reports/initial_study/assignments.parquet --date-decisions ../reports/enrichment_v2/code_bridge_adjudication/calendar_code_adjudication.csv --output data/replay-population-panel
```

Сохраните `evidence/` рядом с CSV календарных решений: скрипт проверяет пути и SHA-256 каждого доказательства. Шесть решений снимают только конкретный календарный конфликт кода и даты. Они не устанавливают юридическую эквивалентность границ и не подтверждают сопоставимость населения с постоянной географией СберИндекса.

Соединение выполняется по точным региону, исходному коду, дате и типу населения. Муниципальные названия служат подписями и не входят в ключ соединения. Ожидаемый результат: 8 064 строки длинной панели, 4 032 строки широкого формата, 6 940 заполненных `analysis_value`, 1 124 незаполненные ячейки и 2 948 вычисленных долей городского населения. По каждой дате должны оставаться все 2 016 муниципалитетов.

## Пересчитать сводки поставки

Следующая команда читает таблицы из канонических `population/` и `population_source/`, а подписи муниципалитетов из `data/derived/enrichment/municipal_crosswalk_*.csv`.

```text
uv run --frozen python scripts/summarize_population_delivery.py --repo-root .. --report-dir ../reports/enrichment_v2
```

Она заново записывает только сводку, таблицу пробелов и региональное покрытие в выбранном каталоге отчёта. Для изолированного воспроизведения сначала создайте отдельную копию каталога отчёта, поместите результаты повторного запуска в её `population/` и `population_source/`, затем передайте эту копию через `--report-dir`.

## Критерии приёмки и ограничения

Сравнивайте точные ключи, целочисленные значения, исходные маркеры пропуска и статусы с каноническими таблицами. Для CSV канонического Linux-запуска SHA-256 равен `e0675fc634937cb8e856ea1891709152303ba69c3fe3a80bb6876884d2ade895`. Переносы строк на другой ОС могут изменить байтовый хеш CSV; это не разрешает отличия в ячейках. Собственный manifest повторного запуска должен совпадать с собственными файлами. Даты запуска, пути и сведения об окружении в двух manifest закономерно различаются.

Исходный сетевой проход и повторный разбор выполнялись в существующем серверном окружении. Проверка 9 настоящих московских ответов другим агентом подтвердила 36 ячеек, их физические строки и параметры запросов. Полный независимый запуск после распаковки ZIP на чистой машине пока не проведён. Повторное обучение исходной модели, воспроизведение всех поисковых результатов и генерации DeepSeek в эту проверку не входят.

За обновления отвечает сопровождающий репозитория. При смене формата источника, кодов, календарных решений или значений создайте новую версию результата, сохраните предыдущие ответы и выполните проверки заново. Заменять источник модельной догадкой, подставлять ноль вместо отсутствующего значения или переносить население со старого муниципального кода на новый без доказанной связи нельзя.
