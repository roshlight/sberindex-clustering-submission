# Словарь городского ценового слоя

Ключи и роли таблиц:

| Файл | Зерно и ключ | Роль |
|---|---|---|
| `bridge_v2/official_base_cities.csv` | год × официальный город/регион; проверена полная нумерация перечня | Региональная принадлежность наблюдаемого города, страница и строка первичного перечня |
| `bridge_v2/bridge_candidates.csv` | 592 строки город × год | Все исходные городские ИСЖ, включая непринятые и отсутствующие |
| `bridge_v2/bridge_approved_evidence.csv` | 548 принятых связей город × год | Город, точный код населённого пункта, оба муниципальных родителя, строки ОКТМО и происхождение |
| `bridge_v2/city_context_observations.csv` | 429 числовых город × год основной панели | Аналитически доступный городской ИСЖ; не окружной дефлятор |
| `bridge_v2/primary_cohort_city_context.csv` | 4032 строки МО × год | Полная сетка 2016 × 2; отсутствие контекста оставлено пустым |
| `monthly_v3/city_monthly_price_cells.parquet` | год × месяц × `source_city_code_literal` × `product_code` | Все 3 836 682 фактически опубликованные городские клетки; спорный городской месяц сохранён |
| `monthly_v3/city_monthly_dimensions.csv` | год × месяц × исходный код города | Название и регион, принятый муниципальный контекст или причина изоляции |
| `monthly_v3/product_dictionary.csv` | год × месяц × код товара | Полное исходное название с единицей и номер столбца; используется каждый месяц отдельно |
| `monthly_v3/primary_city_price_context.parquet` | исходная клетка + принятый `territory_id` | 2 933 362 клетки городского контекста основной панели после изоляции конфликта |
| `monthly_v3/yearly_source_coverage.csv` | год | Номинальная сетка, фактическая публикация, числа/маркеры/нули/пропущенные столбцы |
| `monthly_v3/city_year_coverage.csv` | год × исходный код города | Покрытие кода, не обязательно одного неизменного города в течение года |
| `monthly_v3/product_primary_coverage.csv` | год × товар | Доступность товара в принятой выборке; `published_months` отражает наличие столбца |

ИСЖ: `value` — отношение к среднему по России, где Россия равна 1; годовой показатель на среднегодовых ценах. `source_cell`, `source_sheet`, `source_sha256`, `source_url` относятся к исходной книге ИСЖ. `source_city_oktmo_11` — строковый код населённого пункта из раздела 2; `source_parent_oktmo_11` — существующий код верхнего МО; `source_immediate_parent_oktmo_11` может относиться к городскому поселению внутри района. Коды сохраняют ведущие нули. `DateUtv` и `DateVved` переписаны из классификатора и не объявлены датой фактического изменения границ.

`approved_evidence` означает, что выполнено документальное соединение для контекста города. Оно не означает независимой проверки муниципальных границ, репрезентативности городских цен для всего МО или допуска к любой модели. `city_only_listed_settlement_in_parent` относится только к перечню населённых пунктов данного снимка ОКТМО.

Месячные цены: `value` — числовая цена в рублях за единицу, указанную в полном названии товара, на конец месяца. `product_code` — исходный код товара, не ОКВЭД и не категория СберИндекса. Наименования 570 кодов не менялись между прочитанными листами, но код `9261` отсутствует в ноябре/декабре 2024 года. Отдельного показателя «средняя цена всех товаров» здесь нет.

`source_city_code_literal` — буквальная десятичная запись числового кода, прочитанного из столбца A книги. Ведущий ноль не добавляется автоматически. Этот столбец не называется ОКТМО и не используется для прямого соединения с муниципальной панелью. Исходные коды для известных городов согласуются с ОКАТО в методологии 440, за исключением отдельно зарегистрированного конфликта. Городской контекст соединяется через проверенный составной ключ и годовой ОКТМО.

`source_row` и `source_column` — номера с единицы в месячном листе `MM(YYYY)`. Книга определяется годом и `source_workbooks.csv`. Полный локатор: исходный SHA + лист + номер строки + номер столбца. `source_raw_value` сохраняет строковое представление значения, прочитанного библиотекой из XLSX; для чисел это не обещание идентичности текстовому XML-лексему. Бинарный оригинал и независимый XML-replay сохраняют проверяемость исходной точности.

`temporal_review_required`, `temporal_review_roles` и `registry_{city,parent,immediate_parent}_{DateUtv,DateVved,CHANGE}` сохраняют отдельную календарную проверку каждой роли. `temporal_review` исключает связь из approved-слоя; кандидат и исходные числа остаются. В месячных измерениях `candidate_territory_id` служит только указателем непринятого кандидата, `temporal_review_reason` хранит причину. Этот указатель нельзя использовать как разрешённый муниципальный ключ.

Статусы клетки:

- `observed`: положительное число источника;
- `observed_zero`: источник содержит числовой ноль; его экономический смысл отдельно не установлен;
- `source_marker`: исходный `...`, `…`, `-` или `—`; `value=NULL`;
- `source_blank`: пустая опубликованная клетка; в этих книгах среди извлечённых городских клеток таких нет.

Отсутствующий товарный столбец не порождает искусственных строк. Разница с номинальной сеткой явно посчитана в `absent_product_column_cells`. `source_code_review` — статус географической атрибуции городского месяца, а не статус каждой цены. Такие числа находятся в полном исходном Parquet, но не в `primary_city_price_context.parquet`.

Правила соединения: только по полному составному ключу из словаря. Нельзя присоединять месячные цены к городским измерениям по одному коду без года и месяца; один код Вышнего Волочка в 2023 году меняется между месяцами. Нельзя соединять товарный словарь только по позиции столбца. Нельзя считать NULL нулём, переносить цену на соседнее МО или усреднять рубли за килограмм, поездку и месяц услуги.
