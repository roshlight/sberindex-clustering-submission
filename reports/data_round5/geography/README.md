# Коды МСП: современный справочник и исторические версии

Получены два полных официальных CSV ОКТМО, помеченные **01.06.2026** и **01.07.2026**, а также текущий паспорт набора. Четыре ранее проверенные версии 2023/2024 повторно использованы с прежними хешами. Это справочный слой для дальнейшего разбора географии МСП, а не принятое присоединение к муниципальной панели.

Источник: [Росстат, ОКТМО](https://rosstat.gov.ru/opendata/7708234640-oktmo). `registry_versions.csv` содержит URL, даты получения, происхождение, SHA-256, число строк и максимальную дату введения записей. В старых файлах есть записи, вводимые позднее даты в имени; например, версия 19.12.2023 содержит изменения с 01.01.2024. Дату имени файла нельзя считать снимком действующей популяции кодов на этот день.

Проверены все **15 440 928 строк периодов** двух полных годовых файлов МСП `v20260605`. Сформированы **160 690 групп «год × исходный код»**, включая отсутствие кода. Публикуются агрегаты, без ИНН и названий отдельных организаций. Число различных ИНН внутри одного кода не складывается по кодам: один ИНН может встречаться с разными кодами.

Знаменатели — **7 555 943 / 7 884 985 строк**, включая строки без кода. Это полнота точного поиска кода, а не доля организаций с доказанным историческим адресом. Сопоставление всех годовых файлов со всеми версиями сделано намеренно; позднюю версию не принимаем за историческую истину.

## Наличие кода ещё не означает муниципальную детализацию

В июньском справочнике **20,2657% / 20,4121%** строк МСП относятся к группировочным кодам раздела 1 с `KOD1=000` — уровню субъекта, включая города федерального значения. Ещё **78,7999% / 78,7202%** строк имеют код населённого пункта раздела 2. Оставшаяся небольшая часть — другие коды раздела 1 либо отсутствие точного соответствия. Точные числители и знаменатели находятся в `code_kind_summary.csv`.

Следовательно, совпадение почти всех кодов с современным справочником нельзя выдавать за готовый муниципальный ключ. Для населённых пунктов нужна проверенная история принадлежности; для группировочных кодов субъекта детальность может быть недостаточной для нашего МО. Совпадение кода не доказывает неизменность адреса организации, состава территории или юридической границы. Префиксное соединение и дополнение кодов нулями не выполнялись.

Между июньской и июльской версиями найдено **74 изменения наличия кода или его названия**. Они перечислены в `june_july_code_changes.csv`; это не число муниципальных преобразований. Сравнение ограничено кодом и названием, остальные поля могут меняться отдельно. Доли присутствия кодов рассматриваемых записей МСП между этими двумя версиями совпали.

## Файлы и проверка

- `sme_code_inventory.csv` — исходные агрегаты кодов, длина и синтаксис; NULL отличён от пустой строки.
- `sme_code_presence.parquet` — точное наличие кода, неоднозначность, название, структурный уровень и исходная дата введения в каждой версии.
- `code_presence_summary.csv` и `code_kind_summary.csv` — результаты с явными знаменателями.
- `registry_duplicate_codes.csv` — проверка неоднозначности. Для выбранных записей во всех шести версиях дубликатов кодов нет.
- `manifest.json` — хеши скрипта, файлов классификатора, двух полных исходных Parquet МСП и результатов.

Новые файлы скачаны через уже настроенный сервер с проверкой TLS. Локальная попытка не прошла сетевое соединение; её три записи об ошибках сохранены отдельно от принятых данных. Повторная передача с сервера использовала сжатый контейнер после прерванного прямого копирования; перед расчётом проверены SHA-256 каждого принятого файла. Ошибка первого серверного запуска была связана с чтением пути к карте публичных сертификатов как JSON; исправлена до загрузки, данные этого запуска отсутствуют.

Из корня репозитория, после распаковки сырья пятого и четвёртого раундов:

```powershell
uv run --project enrichment --frozen python enrichment/scripts/prepare_round5_geography.py --repo . --raw ../../work/data-round5/geography --prior-raw ../../work/data-round5/geography/reused --sme-raw ../../work/data-round4/sme --out work/round5-geography-replay
uv run --project enrichment --frozen pytest enrichment/tests/test_round5_geography.py -q
```

Каталог вывода должен быть новым. Replay не использует сеть. Исходные годовые Parquet МСП уже опубликованы в четвёртом релизе и не дублируются в пятом. Для новой сетевой загрузки из корня репозитория: `uv run --project enrichment --frozen python enrichment/scripts/collect_round5_registry.py --out <новый каталог>`; переменная `PUBLIC_CA_BUNDLES_JSON`, если нужна, содержит путь к карте публичных сертификатов, а не секрет.

Статус: **ready with conditions** — готово для проверки кодов и постановки следующих соединений. Исторические адреса, границы и муниципальные агрегаты МСП не подтверждены; прежние маски не менялись.
