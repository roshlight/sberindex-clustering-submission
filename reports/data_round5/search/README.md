# Серверный поиск пятого раунда

Использованы установленный SearXNG и `deepseek/deepseek-v4-pro-0813` через OpenRouter. Это этап поиска и разбора документов; его карточки не являются источником числовых признаков и не разрешают соединения.

План содержал 15 запросов и 9 заранее выбранных источников. Выполнены 2 поисковых запроса: они дали 20 строк выдачи, но оба ответа содержали ограничения движков. Защита остановила очередь, оставив 13 запросов отложенными. Это не полный проход всех запланированных запросов. Независимый ручной поиск и прямые запросы к официальным источникам продолжены в других ветвях.

Получены 29 уникальных начальных URL с учётом известных источников и ещё 12 переходов по ссылкам. Из 41 кандидата скачаны 15 файлов; у 22 возникла сетевая ошибка, ещё 4 превышали предел размера. Число кандидатов не равно числу полученных наборов данных.

Для 14 документов запрошен модельный разбор; получено 13 карточек, один ответ обрезан (`truncated_completion`). Итоговая модельная проверка выполнена, но она не заменяет сверку исходной таблицы. Повторного запроса обрезанного ответа в этом запуске не было. Сервис сообщил 304 543 входных и 102 900 выходных токенов, 15 HTTP-попыток и стоимость **0.61886695784775 USD**. Зафиксированная стоимость относится только к этому запуску OpenRouter.

Полный снимок `server-complete/data-round5-20260916-01` сохраняет план, выдачу, исходные документы, текст, карточки, ответы моделей, их учёт и снимок реализации. Проверены 157 хешей результатов манифеста и байты загруженных документов. `server_document_inventory.csv` содержит URL и статусы, `server_summary.json` — точные счётчики и ограничения.

Из корня репозитория, после распаковки сырья:

```powershell
uv run --project enrichment --frozen python enrichment/scripts/summarize_round5_search.py --raw ../../work/data-round5/server-complete --out work/round5-search-replay
```

Повтор работает без сети, ключей и новых платных вызовов. Он проверяет сохранённый запуск; повторная поисковая выдача и ответы модели не обязаны совпадать. Для нового сетевого запуска используйте конфигурации `configs/data_round5_needs.json`, `configs/data_round5_sources.json`, существующее серверное окружение и новый каталог запуска. Точный набор параметров сохранён в исходном `run_manifest.json`.
