# Поиск через сервер и проверка источников

16.09.2026 выполнены два запуска существующего конвейера на сервере. Они сохранены целиком в `data-round4-search.zip`: запросы, ответы поиска, исходные документы, тексты, подсказки и ответы модели, метаданные, публичные сертификаты и точный снимок кода. `server_summary.json` получен из двух манифестов с проверкой **118 хешей**; `server_document_inventory.csv` содержит 19 записей документов.

| Запуск | Движки | Запланировано | Выполнено | Отложено | Строк результатов поиска |
|---|---|---:|---:|---:|---:|
| `data-round4-20260916-01` | Google CSE через SearXNG | 15 | 2 | 13 | 0 |
| `data-round4-20260916-02` | DuckDuckGo, Brave через SearXNG | 4 | 2 | 2 | 0 |

В обоих запусках две выполненные поисковые операции получили частичные ответы с ограничениями движков. Защита от повторных запросов отложила остальные. Статус `complete` означает завершение конвейера; успешной поисковой выдачи эти запуски не дали. Семь URL-кандидатов первого запуска пришли из заранее заданного каталога источников.

Прямой сбор первого запуска сохранил шесть HTML-документов. Ещё 12 ссылок отклонены проверкой URL; в найденных адресах встречались неэкранированные пробелы. Одна загрузка PDF Якутиястата завершилась сетевой ошибкой; нужные версии затем получены отдельно и проверены в разделе [кейсов](../cases/README.md). Ограничения URL не отключались. Официальные сайты и документы дополнительно искались через доступный веб-поиск и открывались напрямую; журналы предметных поисков находятся в `cases/search_log.json`, `economy/search_notes.json` и `work/data-round4/geography/inputs/search_log.json` сырьевого архива.

Использована только модель **`deepseek/deepseek-v4-pro-0813`** через OpenRouter. Получены пять карточек источников. Межисточниковая проверка завершилась `ValueError`, поэтому её результата нет. Шесть завершённых HTTP-вызовов модели учтены в стоимости **$0.101657449533**: 35 512 входных и 35 669 выходных токенов по журналу провайдера. Во втором запуске модель не вызывалась. Карточки служат навигации и не заменяют извлечение чисел из исходных таблиц или визуальную проверку PDF.

Воспроизведение сводки без сети из корня репозитория:

```powershell
uv run --project enrichment --frozen python enrichment/scripts/summarize_round4_search.py --raw ../../work/data-round4/server-complete --out ../../work/data-round4/search-replay
```

Повторный сетевой поиск создаёт новую версию и не обязан вернуть те же страницы. Сохранённые журналы позволяют проверить, какие запросы были выполнены, что не удалось получить и какие файлы послужили основанием выводов.
