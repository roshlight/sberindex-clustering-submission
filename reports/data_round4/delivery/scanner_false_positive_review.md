# Проверка ложного срабатывания сканера

**PASS: одно конкретное совпадение относится к служебной таблице JPEG внутри PDF.** Байты, совпавшие с регулярным выражением, не публикуются. Исключение применяется только к неизменённому содержимому `work/data-round4/geography/raw/pit_planning_materials.pdf` и точному совпадению ниже.

| Проверяемое свойство | Значение |
|---|---|
| Размер PDF | 1055501 байт |
| SHA256 PDF | `f95741def9af964fbbb1b505cf52cba5b13eb74b197ede960abeabac25d50ea1` |
| Начало совпадения, от нуля | 596649 |
| Длина совпадения | 41 байт |
| SHA256 совпадения | `2bd445e4a1c907caa85db7ba09b0aed51556373edb48b41d5e431b38f24416cd` |
| Всего совпадений исходного сканера в файле | 1 |

Проверены две независимые части структуры. PDF-парсер извлёк объект **128**, `/Subtype /Image`, `/Filter /DCTDecode`, размер изображения **491×324**. Его JPEG-поток длиной **21478** байт в точности совпал со срезом исходного файла, начинающимся на **596100**. SHA256 потока — `c01ee8d56dbd4b76dee8481c41bb2c009d8aae8c1eaa3004129977f875e47cf5`; присутствуют маркеры SOI и EOI.

От SOI отдельно разобрана последовательность JPEG-маркеров и их объявленных длин. Сегмент **DHT** занимает полуинтервал **[596342, 596762)**, его поле длины равно **418**. В нём находятся четыре таблицы Хаффмана. Совпадение **[596649, 596690)** целиком находится в массиве **162** символов таблицы класса **AC**, идентификатор **1**: **[596600, 596762)**. Это позиции **49–89** массива, если считать от нуля. Совпадение не затрагивает заголовок или массив длин кодов. Проверены границы всех четырёх таблиц и отсутствие переполнения дерева по числу кодов каждой длины. Утверждение относится к этому JPEG, а не к любым бинарным данным, похожим на JPEG.

## Правило нового упаковщика

Создан `enrichment/scripts/package_round4_delivery.py` с теми же аргументами `--work`, `--repo`, `--allowlist`, `--out`. Старый `package_round2_delivery.py` не изменён; его SHA256 — `5bbdd46528947d3ee96db825f6f337e3cd0e7391411b13fb3312833a4ebb5c6f`. Регулярное выражение сохранено побайтово; отдельный тест сравнивает его с выражением в старом коде.

Исключение требует одновременно совпадения полного размера и SHA файла, смещения, длины и SHA совпадения, SHA JPEG-потока и точных границ DHT-таблицы. Структурный разбор выполняется заново при проверке. Исключение встроено в код и не настраивается из CLI. Имя файла само по себе ничего не разрешает. Сканер проходит по **всем** совпадениям; разрешённый участок не освобождает остальной файл от проверки.

Внутренний и внешний manifest нового упаковщика сохраняют политику сканирования, SHA регулярного выражения и метаданные реально применённых исключений в `credential_scan.exceptions_applied`. QA сохраняет `audited_exceptions_applied` и `credential_scan_exceptions`. Ни в manifest, ни в QA нет совпавших байтов. Если точный PDF не входит в архив, число применённых исключений равно нулю; все прочие совпадения блокируются.

## Проверки

**11 тестов PASS, пропущенных нет; Ruff PASS.** Среди проверок: реальный неизменённый PDF; изменение байта вне совпадения; добавление второго токена; проверка всех точных координат совпадения; попадание в заголовок DHT вместо символов; подмена типа JPEG-сегмента; сохранение блокировки исходных классов секретов. Дополнительный синтетический тест разрешает первое совпадение на уровне ожидаемого полного SHA, но всё равно требует блокировки второго: исключение не превращается в разрешение всего файла.

```powershell
uv run --project enrichment --frozen --offline pytest enrichment/tests/test_round4_delivery_scanner.py -q
uv run --project enrichment --frozen --offline ruff check enrichment/scripts/package_round4_delivery.py enrichment/tests/test_round4_delivery_scanner.py
```

Реальный PDF для последнего теста берётся из отдельного raw-пакета по указанному пути; при его отсутствии именно этот тест будет явно пропущен. В текущей проверке PDF присутствовал. Скрипт `work/package_round4.py` прочитан только для проверки интерфейса. Реальная упаковка этим новым упаковщиком не запускалась, старые архивы и исходный PDF не менялись. Все контрольные суммы и структурные результаты сохранены в `scanner_false_positive_review.json`.
