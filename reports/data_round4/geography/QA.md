# Проверка пакета географии, раунд 4

**PASS для воспроизведения поставленных версий; UNKNOWN для независимого подтверждения исторических юридических границ.**

| Проверка | Итог |
|---|---|
| SHA и размер доступных исходных документов/наборов | PASS, 14 источников |
| Свежий metadata PDF против прежнего | PASS, байты совпадают; обновление методологии не установлено |
| Уникальность выбранной атрибутной и геометрической версии | PASS, 4 МО × 2 года = 8 строк |
| Одинаковые BLOB-байты геометрии 2023/24 | PASS, 4 из 4 конкретных МО |
| Повторная офлайн-сборка против поставленных результатов | PASS, все генерируемые файлы совпали побайтово |
| Содержательные unit tests | PASS, 3 теста |
| Ruff check / format | PASS |
| Новые парные независимые исторические геометрии | 0; сопоставимость остается UNKNOWN |
| Вычисление пересечения и площади расхождения | NOT RUN |
| Автоматическое изменение старых масок | 0 |

Тесты проверяют исключение `year_to`, отказ при двух или нуле подходящих версий, различение равных и изменившихся геометрических байтов, сохранение unknown/календарного флага при равных байтах и отказ при изменении входного SHA. Проверка заголовка `GP` не объявляется полной геометрической валидацией.

Визуально просмотрены титул генплана Питкяранты с 2025 годом, одностраничная карта функциональных зон и титул устава 2019 года. Семантика страниц метаданных проверена по извлеченному тексту. Старые правовые акты включены из раунда 3 с прежними SHA; в этом раунде не заявляется повторная постраничная юридическая экспертиза всех приложений.

Первоначальный журнал получения карты сохраняет ошибку кодировки вывода в консоль после успешного скачивания. Файл существует, начинается с `%PDF`, имеет одну страницу, извлечен и визуально проверен; его статус `downloaded` основан на этих проверках. Ошибка не скрыта из исходного журнала.

Для одного discovery-источника gov10 сохранены ошибка проверки сертификата и последующий HTTP 403; повторные попытки не продолжались. Неудачные обращения к NSPD/консолидированной правовой странице не превращены в доказательство отсутствия данных вообще. Новые сведения ограничены реально полученными файлами.

Метка PASS относится к указанным вычислениям и целостности. Она не устанавливает точность OSM, юридическую неизменность внешней границы, полноту ЕГРН, пространственную сопоставимость числителей Росстата или календарную допустимость городского кода `19514000001` на 01.01.2023.
