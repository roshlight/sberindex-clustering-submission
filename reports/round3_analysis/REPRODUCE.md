# Воспроизведение третьего раунда анализа

Проверки `verify_*_bundle.py` сверяют исходные тексты документов. Выполняйте их в [копии с первоначальной документацией](../../submission/REPRODUCE.md#проверка-исторических-контрольных-сумм); расчётные команды и данные от редакционных изменений не зависят.

Расчёт использует сохранённые таблицы и существующий Python 3.12 / `uv.lock`. После установки зависимостей сетевой доступ для числовой проверки не требуется. Третья коллекция зафиксирована коммитом `296063dcd5af98d2203a20332947b6a0039e041f`; исходные файлы опубликованы в [релизе данных](https://github.com/roshlight/sberindex-clustering-submission/releases/tag/data-round3-2026-09-16). В этом раунде источник, прежние маски и модели второго раунда не изменялись.

Команды ниже выполняются из корня репозитория. Для повторного расчёта укажите новые папки: модельный скрипт не перезаписывает существующий результат.

```powershell
uv sync --frozen
uv run --frozen pytest -q
uv run --frozen ruff check .
uv run --frozen python scripts/verify_round3_bundle.py
uv run --frozen python scripts/verify_round3_analysis.py --out work/round3-independent-replay.json
```

Проверка `verify_round3_analysis.py` восстанавливает исходные значения, исторические ключи, флаги, цели и разбиения; независимо обучает все 560 Ridge-моделей через NumPy; пересчитывает 224 строки метрик, 224 сравнения с 2000 перевыборками регионов и 676 срезов. Допуск для OOF-прогнозов — численный, а не требование побайтового совпадения разных алгоритмов линейной алгебры. Независимые результаты, ограничения и максимальные отклонения записаны в [independent_QA.json](independent_QA.json) и [independent_review.md](independent_review.md).

## Повтор отдельных этапов

```powershell
uv run --frozen python scripts/round3_data_audit.py --repo . --out work/round3-replay/audit
uv run --frozen python scripts/round3_context_analysis.py --repo . --out work/round3-replay/context
uv run --frozen python scripts/round3_model_analysis.py --repo . --out work/round3-replay/models
uv run --frozen python scripts/plot_round3_analysis.py --root reports/round3_analysis --out work/round3-replay/figures
uv run --frozen python scripts/build_round3_report.py --repo . --out work/round3-replay/report
```

Аудит и контекст читают сохранённые источники. Модельный скрипт читает опубликованный `audit/annual_features.csv`, прежнюю модельную панель и конфигурацию `configs/round3_analysis_v1.json`. Сначала сравните восстановленные признаки с опубликованными: оба варианта аудита дали одинаковые SHA-256. Фигуры и отчёт читают сохранённый числовой результат, без нового обучения. Метки времени в модельном манифесте не обязаны совпадать между запусками. Смысловые определения и условие принятия блока не меняются при повторе.

Структура пакета:

- `audit/` — 4032 строки признаков, исторические связи, причины пропусков, покрытия и словарь.
- `models/` — панель, 210 968 строк OOF-прогнозов, подготовка признаков по folds, метрики и все сравнения.
- `context/` — 18 годовых пар шести МО, 53 документальные записи и 10 проверок сопоставимости.
- `figures/` — три PNG/SVG, исходные строки CSV и результаты визуального QA.
- `artifact.json` — канонические данные и блоки отчёта; `report.html` — самостоятельный интерактивный файл; `REPORT.md` — версия для чтения в GitHub.

Все новые признаки рассматриваются ретроспективно. MSE профиля в таблице усреднена по пяти координатам, а потери отдельного МО в bootstrap и срезах суммируются по ним. Относительный выигрыш и R² от этого множителя не зависят.

## Сборка интерактивного отчёта

Использован установленный Data Analytics 0.2.10. Канонический `npm run report:deliver` обнаружил горизонтальное переполнение заголовка при системной полосе прокрутки Windows. Применён ранее проверенный локальный сборщик с одной CSS-поправкой ширины заголовка; встроенные данные и runtime не менялись. HTML повторно проверен штатным валидатором. Подробности, SHA-256 и параметры проверки сохранены в `portable_delivery.json`.

Для аналогичного окружения укажите путь к установленному плагину и новую выходную папку:

```powershell
node scripts/build_round2_portable.mjs --plugin <DATA_ANALYTICS_PLUGIN> --input reports/round3_analysis/artifact.json --output work/round3-replay/report.html --receipt work/round3-replay/portable_delivery.json --work-dir work/round3-native-build
```

Проверка HTML охватывает ширины 1440 и 390 px, соответствие каноническому artifact, три графика, десять таблиц и меню источника; внешние запросы запрещены. Это не сертификация всех браузеров или печати. Отдельные исследовательские PNG осмотрены визуально. Светлая/тёмная системная тема штатного читателя сохранена.

Протокол заранее фиксировал отрицательные и неполные результаты как допустимый исход. Блок не прошёл условие добавления к ядру модели; воспроизведение не должно подбирать признаки, разбиения или гиперпараметры для изменения этого решения.
