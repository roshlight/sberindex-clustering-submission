# Фигуры третьего раунда анализа

Три исследовательские фигуры доступны в PNG и SVG; для каждой сохранён CSV с исходными строками и числовыми преобразованиями для осей. Модели при построении не запускаются.

| Фигура | Источник | Содержание |
|---|---|---|
| `activity_coverage` | `../audit/coverage.csv` → `coverage_chart.csv` | Числовые значения трёх показателей на frozen core, 2023/2024; каждая подпись содержит числитель и знаменатель |
| `profile_increment` | `../models/cv_comparisons.csv` → `profile_increment_chart.csv` | `profile_clr`, seed 13, `economic_sectors_newflags` → `economic_sectors_newvalues`; три выборки, два года и два режима |
| `log_total_negative_control` | `../models/cv_comparisons.csv` → `log_total_control_chart.csv` | `log_total`, core, seed 13; реальные и `permuted_newvalues` относительно одной базы `economic_sectors_newflags` |

На forest-графиках показано `100 × relative_mse_reduction`: справа от нуля ошибка меньше базовой. Границы интервалов взяты непосредственно из `ci_low` и `ci_high` и умножены на 100. Интервалы относятся к перевыборке регионов при фиксированных OOF-прогнозах, без переобучения моделей; они не охватывают все источники неопределённости исследования.

Все 12 интервалов первичного сравнения включают ноль. Дополнительная информация новых чисел для потребительского профиля этим сравнением не подтверждена. Для `log_total` при проверке на регионах вне обучения точечные выигрыши перемешанных значений больше реальных в обоих годах. Это ограничивает содержательную трактовку вторичных улучшений. Использована одна фиксированная перестановка наблюдаемых значений внутри региона, отдельно в обучении и проверке: региональные распределения и пропуски сохраняются. Это диагностический контроль, а не полное распределение нулевой гипотезы и не тест причинности.

Из корня репозитория, указав новую папку:

```powershell
uv run --frozen python scripts/plot_round3_analysis.py --root reports/round3_analysis --out ../../work/round3-analysis/figures-replay-new
uv run --frozen ruff check scripts/plot_round3_analysis.py
uv run --frozen ruff format --check scripts/plot_round3_analysis.py
```

Числовой QA — PASS: проверены уникальность и полный набор 6/12/8 строк, конечность оценок и интервалов, одинаковая база и знаменатели реального/перемешанного сравнения, сохранность входных файлов. Все три финальных PNG осмотрены через `view_image`; обрезанных подписей и наложений нет. Годы и серии различимы не только цветом: используются штриховка, форма/заливка маркеров и прямые подписи. Цвета и шрифт сохранены из предыдущего раунда. `QA.json` и `manifest.json` фиксируют проверки и SHA256.
