Поставляемый вывод ограничен вопросом: меняет ли восстановление денежных показателей прежнее решение об их добавлении к модели потребительского профиля? Основная и консервативная выборки, цели, разбиения и критерий принятия сохранены. Критерий не выполнен. Это результат исследовательского сравнения, а не доказательство отсутствия экономической связи.

Штатная первоначальная сборка HTML обнаружила переполнение заголовка при системной полосе прокрутки Windows. Ранее проверенный сборщик добавил одну CSS-поправку ширины, затем повторил штатную проверку. Данные, сжатый runtime и файлы установленного плагина не изменены. Диагностический снимок неудачной сборки остаётся локальным служебным файлом; финальный HTML и результат успешной проверки включены в поставку. Это не проверка всех браузеров или печати.

Окружение: Windows AMD64, Python 3.12.10; NumPy 2.5.3, pandas 3.0.5, scikit-learn 1.9.1, SciPy 1.18.1, DuckDB 1.5.5, Matplotlib 3.11.2, pytest 9.1.1, Ruff 0.16.7. Зависимости зафиксированы корневым `uv.lock`. HTML собран Node.js 22.23.2 и установленным Data Analytics 0.2.10. Секреты для числового анализа не нужны; скачивание частного GitHub-пакета требует доступа участника организации.

Редакторская проверка сохраняет числа и ограничения. Уточнены единицы: 770 новых значений трёх признаков, уникальные ИНН за год, знаменатели отраслевой наблюдаемости и отсутствие парных датированных координатных описаний юридических границ. Основной вывод не усиливался. SHA-256 итоговых файлов и скриптов зафиксированы в `delivery_manifest.json`; проверка: `uv run --frozen python scripts/verify_round4_bundle.py`.
