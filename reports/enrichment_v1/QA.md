# Проверка поставки

Поставка добавляет отдельный пайплайн поиска и числового обогащения. Она не меняет модельный эксперимент первой версии и не подтверждает новые экономические гипотезы.

| Проверка | Статус | Свидетельство и предел |
|---|---|---|
| Тесты отдельного проекта `enrichment` | PASS | 151 тест выполнен локально и на сервере; `uv run --frozen pytest -q` |
| Стиль и формат `enrichment` | PASS | Локально выполнены `uv run --frozen ruff check .` и `uv run --frozen ruff format --check .` |
| Новый парсер муниципального справочника | PASS | 10 тестов `tests/test_prepare_municipal_crosswalk.py` и Ruff для нового скрипта и тестов |
| Сохранность первой поставки | PASS | Все 62 файла из `reports/initial_study/delivery_manifest.json` совпадают по SHA-256; финальная проверка записана в `delivery_manifest.json` текущей поставки |
| Числовые расчёты на сервере | PASS | Справочник, контекст 2024, бюллетени населения, пилот БДПМО и кодовое соединение выполнены на сервере; хеши экспортированных результатов проверены |
| Основной поиск с моделями | PASS WITH WARNINGS | `research-20260914-01` завершён; 40 карточек и сопоставление источников. Ограничения поискового движка и одна обрезанная генерация сохранены в журнале |
| Дополнительный проход | PARTIAL | `recovery-20260914-01` сохранил 2 карточки, но завершился отказом OpenRouter 403; итоговый модельный обзор этого прохода отсутствует |
| Последняя версия загрузчика на двух первичных PDF | PASS WITH WARNINGS | `primary-pdf-20260914-01` прочитал оба PDF без моделей; некорректный заголовок кодировки отмечен явно |

| Независимая внешняя репликация и экономическая экспертиза | NOT RUN | Проверки выполнены агентами текущего проекта; это не независимая экспертная разметка |

Полный исходный набор из 90 тестов модели в этой работе не запускался повторно: исходный код и его зависимости не менялись. Новые тесты относятся к новому пайплайну и парсеру справочника.

Проверка поставки дополнительно сверяет хеши экспортированных файлов, локальные ссылки Markdown и отсутствие строк, похожих на реальные ключи OpenRouter или токены Telegram, в публикуемых файлах. Это ограниченная проверка известных форматов секретов, а не полный аудит безопасности. Её фактические результаты и состав файлов находятся в [delivery_manifest.json](delivery_manifest.json).

Полные источники, кэши, промпты, ответы моделей и журналы HTTP остаются на сервере. Публичные URL и контрольные суммы сохраняют происхождение материала; доступность тех же байтов у издателя в будущем не гарантируется. Потребуется сохранить серверный архив, если источник изменится.
