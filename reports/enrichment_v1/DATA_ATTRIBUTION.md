# Происхождение данных

Справочник кодов и исходная доступность рынков: Лаборатория «СберИндекс», ПАО Сбербанк. [Описание набора](https://sberindex.ru/ru/research/data-sense-opisanie-nabora-dannikh-khakatona-sberindeksa-po-munitsipalnim-dannim), [муниципальный справочник](https://sberindex.ru/ru/research/dataset-borders-and-changes-of-municipalities). Для справочника источник указывает CC BY-SA 4.0 и атрибуцию СберИндексу, Росстату и OpenStreetMap. [Лицензия CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Исходный архив и GeoPackage в эту поставку не включены; подготовлены версии и срезы таблицы кодов. Другие условия исходного конкурсного набора сохраняются согласно [атрибуции первой версии](../../DATA_ATTRIBUTION.md).

Население, БДПМО и исторический классификатор ОКТМО: Федеральная служба государственной статистики (Росстат). [Бюллетени населения](https://rosstat.gov.ru/compendium/document/13282), [БДПМО](https://rosstat.gov.ru/storage/mediabank/MUNST.htm), [открытые данные ОКТМО](https://rosstat.gov.ru/opendata/7708234640-oktmo). Отдельная лицензия для каждого из этих файлов при сборе не установлена; лицензия СберИндекса автоматически на них не переносится.

Изменения при подготовке: выбор срезов справочника и основной панели, преобразование формата числовых таблиц, сохранение исходных строк и QA, точное кодовое соединение проверочного набора. Числа населения не заменялись модельными оценками или догадками. Во всех таблицах и манифестах сохранены дата измерения, URL, исходное представление кода и/или хеш источника. Подробности преобразований находятся в аудите каждого слоя.

Материалы подготовлены для внутренней исследовательской работы команды. Перед внешней публикацией расширенного набора следует уточнить условия повторного распространения тех источников, где они ещё не установлены. Этот файл не меняет условий правообладателей и не распространяет лицензию программного кода на данные.
