Начните с [результатов](../../../reports/enrichment_v2/REPORT.md), [готовой годовой таблицы](../../../reports/enrichment_v2/population/municipal_population_wide.csv) и [списка пропусков](../../../reports/enrichment_v2/population_gaps.csv). Канонический исходный разбор — `population-bulk-20260915-v3`. Варианты v1 и v2 сохранены как история исправлений и не являются итоговой таблицей.

Оба ZIP содержат `ARCHIVE_MANIFEST.json`. Общий [манифест](archives_manifest.json), [серверный каталог](server-file-catalog.json), [локальный каталог](local-file-catalog.json) и [SHA256SUMS](SHA256SUMS.txt) фиксируют точные байты. Проверка скачанных архивов из корня репозитория:

```bash
python scripts/verify_data_release.py /path/to/downloaded/assets
```

В эту директорию должны быть скачаны оба ZIP и `archives_manifest.json`. Проверка сверяет размеры, SHA256 архивов, безопасные имена и SHA256 каждого вложенного файла без извлечения и выполнения его содержимого. [Результат проверки передачи](verification.json).

Для пересборки числовых таблиц см. [REPRODUCE.md](../../../reports/enrichment_v2/REPRODUCE.md). Серверный ZIP использует пути от корня репозитория (`enrichment/data/...`). Локальный ZIP сохраняет структуру рабочего пространства с `work/...` и `outputs/municipal-economic-profiles/...`. Источники для отдельного аудита подписей уже присутствуют в серверном кэше; их можно найти по SHA256, даже если локальная копия проверяющего называлась иначе.

Сырые файлы сохранены без изменения. В сгенерированных серверных JSON и Markdown абсолютный корень проекта заменён относительным; каталог хранит исходный и архивный SHA256. Исторические манифесты описывают исходные прогоны, а целостность ZIP проверяется по его `ARCHIVE_MANIFEST.json`. Число файлов не обозначает число независимых источников или пригодных наборов.

Архивы имеют статус **archival evidence only**; числовая поставка в целом — **replayable with constraints**. Карточки моделей сохраняются как черновики для навигации по источникам. Пропуски не заполнены, результаты исследования не переобучены. Прежние исходники и пилот остаются в [первом релизе](https://github.com/roshlight/sberindex-clustering-submission/releases/tag/data-2026-09-15).

Источники и их условия сохраняются: [атрибуция СберИндекса](../../../DATA_ATTRIBUTION.md), [внешние данные](../../../reports/enrichment_v1/DATA_ATTRIBUTION.md), [новый реестр источников](../../../reports/enrichment_v2/code_bridge_sources.json). Архив не меняет условия издателей. Ключи, настройки сервисов и переписка команды в него не входят.
