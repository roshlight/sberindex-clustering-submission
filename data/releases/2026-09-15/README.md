# Все найденные данные: архив на 15 сентября 2026 года

**Статус: archival evidence only.** Эта поставка сохраняет собранные материалы первого кейса и позволяет проверить их байты. Новый анализ, повторное обучение и независимое воспроизведение исследования при архивировании не выполнялись.

Скачать архивы можно в [Assets релиза data-2026-09-15](https://github.com/roshlight/sberindex-clustering-submission/releases/tag/data-2026-09-15). Всего **770 файлов**, **406 523 723 байта** в двух ZIP (около 407 МБ); после распаковки содержимое занимает 749 783 432 байта без служебных манифестов.

Точный состав, размеры и SHA-256 находятся в [archives_manifest.json](archives_manifest.json), [серверном каталоге](server-file-catalog.json) и [локальном каталоге](local-file-catalog.json). В каждом ZIP также есть `ARCHIVE_MANIFEST.json`. Записи каталога описывают физические файлы; число файлов не равно числу независимых источников или пригодных наборов данных.

Данные покрывают исходный конкурсный набор 2023–2024 годов и дополнительные источники, полученные при подготовке проекта. Часть найденных документов относится к другим датам или не подходит для нашего анализа: они сохранены как результат поиска, без автоматического включения в аналитическую панель. Архив не содержит ещё не выполненную массовую выгрузку населения.

## Какие файлы использовать

- **Исходники:** `data/raw/` серверного архива и исходные файлы локального дополнения. Исходные байты сохраняются без изменений.
- **Проверенные производные таблицы:** [reports/enrichment_v1](../../../reports/enrichment_v1/REPORT.md) в репозитории. Соответствующие серверные таблицы также сохранены в архиве. Контекст содержит 2016 МО, доступность рынков наблюдается для 2004.
- **Население:** бюллетени смешивают территориальные уровни. 1627 соответствий классификатору — кандидаты для получения данных, а не покрытие панели населением; 389 ID требуют разбора. Присоединённый пилот охватывает 3 МО, из них 2 входят в основную панель.
- **Модельные материалы:** каталоги `cards`, `prompts`, `model_calls` и `cross_source_review.json` сохраняют черновики. Известные смысловые ошибки описаны в [проверке свидетельств](../../../docs/enrichment_evidence_review.md). Их нельзя принимать за факты только по наличию цитаты.
- **Ранняя выгрузка муниципального портала:** сохранена как отдельная версия источника. Соединение по названиям ненадёжно; для основной работы используйте проверенный версионный справочник кодов.

Первые две поставки исследования остаются неизменными. Указание «файлы только на сервере» в прежнем манифесте описывает состав той поставки; текущий релиз расширяет его архивом исходных материалов.

## Скачать и проверить

Из корня клонированного репозитория, с установленными GitHub CLI и Python 3.12:

```text
gh release download data-2026-09-15 --repo roshlight/sberindex-clustering-submission --dir work/source-data-20260915
python scripts/verify_data_release.py work/source-data-20260915 --manifest data/releases/2026-09-15/archives_manifest.json
```

Скрипт сравнит размеры и SHA-256 обоих ZIP, проверит полный состав и хеш каждого файла внутри. Он не извлекает и не выполняет содержимое. При расхождении завершится с ошибкой. После `PASS` архивы можно распаковать обычным архиватором в разные каталоги.

Для этой проверки не нужны SearXNG, OpenRouter или платные вызовы моделей. Повторный поиск требует доступа к серверу и действующего ключа, а ответ внешней модели не обязан совпадать побайтно. Команды числового пайплайна и зависимости описаны в [enrichment/README.md](../../../enrichment/README.md).

В сгенерированных метаданных серверный или локальный корень пути заменён относительным обозначением. Для изменённого файла каталог хранит и исходный SHA-256, и SHA-256 архивной версии. Исторические манифесты внутри архива продолжают описывать свой исходный запуск; проверка текущей поставки использует `ARCHIVE_MANIFEST.json`.
