# Определения метрик и границы применения

`evaluate_partition(X, labels, adjacency, distances=None)` принимает согласованные
строки признаков, метки и симметричную неотрицательную взвешенную матрицу CSR без
петель. В этом проекте `X` содержит квадратные корни нормированных пяти
опубликованных категориальных средних. Функция не превращает эти значения в
доказанные доли бюджета домохозяйства и не выполняет дополнительное масштабирование.
Смысл нормировки устанавливается отдельно от вычисления метрик.

Результат содержит `silhouette`, `calinski_harabasz`, `s_dbw`, `avi`, `avu`,
`modularity`, `n_clusters`, `smallest_cluster_size`, `largest_cluster_share`,
`partition_status` и словарь `metric_status`. Все числовые результаты имеют обычные
Python-типы. Неопределённое значение представлено `float('nan')` с причиной.
При записи строгого JSON вызывающий код должен заменить NaN на `null`, сохранив
статус; ноль вместо неизвестного значения недопустим.

Все метки, включая `-1`, обозначают обычные группы. Строки не исключаются.
Несовпадение размеров, нечисловые/нефинитные признаки, пропуски меток,
отрицательные веса, существенная асимметрия и петли вызывают `ValueError`.
Входные массивы не меняются. Численная асимметрия CSR в пределах
`1e-12 + 1e-10 * max(weight)` усредняется с транспонированной матрицей.
Для предоставленных расстояний проверяются форма, конечность, неотрицательность,
нулевая диагональ и симметрия. Их соответствие евклидовым расстояниям между
строками `X` является обязанностью вызывающего кода; оно не доказывается повторным
вычислением всей матрицы.

## Геометрия признаков

**SW.** Используется `sklearn.metrics.silhouette_score`: среднее
`(b_i - a_i) / max(a_i, b_i)`, где `a_i` — среднее расстояние до своей группы,
`b_i` — минимальное среднее расстояние до другой. Больше лучше. Расстояние
евклидово; при переданной матрице включается `metric='precomputed'`. Singleton
в нетривиальном разбиении получает значение 0 по соглашению scikit-learn.

**CH.** Используется `sklearn.metrics.calinski_harabasz_score`:
`(SSB / (K-1)) / (SSW / (N-K))`. Больше лучше. Перед вызовом проверяется `SSW`:
нулевой знаменатель даёт NaN, а не возвращаемую некоторыми реализациями условную
константу. SW и CH описывают выбранную геометрию, а не истинность кластеров.
Определения и условия:
[документация scikit-learn](https://scikit-learn.org/stable/modules/clustering.html#clustering-performance-evaluation).

### S_Dbw: зафиксированный авторский вариант 2002 года

Источник: M. Halkidi, M. Vazirgiannis, *An Introduction to Quality Assessment in
Data Mining*, PKDD 2002, PDF-страницы 69–72. Это tutorial авторов метрики,
определения прочитаны с отрендеренных страниц:
[исходный PDF](https://www.cs.helsinki.fi/events/ecmlpkdd/pdf/halkidi-2.pdf).

Пусть `v_k` — центр `C_k`, `var(C_k)` — вектор популяционных дисперсий (`ddof=0`).
Норма в формулах евклидова:

```text
r = sqrt(sum_k ||var(C_k)||) / K
Scat = mean_k ||var(C_k)|| / ||var(X)||
d_kl(u) = sum_{x in C_k union C_l} 1[||x-u|| <= r]
Dens_bw = 1/[K(K-1)] * sum_{k != l}
          d_kl((v_k+v_l)/2) / max(d_kl(v_k), d_kl(v_l))
S_Dbw = Scat + Dens_bw
```

Меньше лучше. Для всех трёх центров плотность считается на объединении той же
пары групп. Это явно выбранный вариант: реализации с собственными точками каждой
группы в знаменателе могут давать другие числа. Радиус включает множитель `1/K`
**вне** квадратного корня. Индикатор считает точки внутри радиуса, включая границу.
Нулевые радиус, глобальная дисперсия или знаменатель плотности дают NaN.
Они не заменяются добавкой epsilon и не исключаются из среднего.

В [статье 2026 года](https://link.springer.com/article/10.1134/S1064562425700589)
формула 14 печатает обратный индикатор плотности, а формулы 15–16 иначе задают её
поддержку. Наш код не смешивает эти определения: следует указанным авторским
страницам 2002 года. Это документированное различие источников, а не исправление
конкурсной формулы без объяснения.

## Сетевые индексы

AVI и AVU используют **бинарную топологию**: каждое положительное ребро имеет
значение 1. Их значения не отражают величину весов. Сохранять и сравнивать нужно
также плотность сети и размеры групп. Это отдельная оценка от взвешенной
модульности ниже.

Пусть `B = S.T @ A_binary @ S`, где `S` — индикатор принадлежности узлов группам;
`I_k = B_kk`, `E_k = sum_{l != k} B_kl`. В неориентированной сети `I_k` дважды
считает внутреннее ребро, тогда как ребро из группы наружу входит в `E_k` один раз.

```text
AVI = (1/K) * sum_k I_k / (I_k + E_k)
AVU = (1/K) * sum_{k != l} B_kl / (E_k + E_l - B_kl)
```

AVI: больше лучше. AVU: меньше лучше. Источник формул:
Shalileh, Antonov, Tsyplakova, §2.2, формулы 18–21,
[Cluster Validity across Attribute and Network Spaces](https://link.springer.com/article/10.1134/S1064562425700589).
Это непосредственная первичная публикация проверяемых уравнений;
в ней метрики отсылают к Biswas & Biswas (2017).

AVU делится на `K`, не на число упорядоченных пар. При `K=2` и существующих
межкластерных рёбрах он неизменно равен 1 и не различает силу разделения.
У двух групп без внешних рёбер возникает `0/0`: строгий вариант возвращает NaN
с `undefined_zero_pair_boundary`, включая случай совершенно раздельных клик.
Для AVI группа с нулевой суммарной степенью делает общий индекс неопределённым.
Такие группы или пары не выбрасываются из расчёта.

### MQ: взвешенная модульность Newman–Girvan при gamma=1

```text
Q = sum_k [L_k / m - (d_k / (2*m))**2]
```

Здесь `m` — суммарный вес неориентированных рёбер, `L_k` — вес внутренних рёбер
группы, `d_k` — сумма взвешенных степеней её узлов. Модуль возвращает `Q` под
ключом `modularity`. Большие значения означают более выраженное разделение
относительно конфигурационной нулевой модели. Отрицательные значения допустимы.
Единое положительное масштабирование весов не меняет результат.
Источники: [Newman и Girvan (2004)](https://arxiv.org/abs/cond-mat/0308217),
[официальная формула NetworkX](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.community.quality.modularity.html).

§6.1 положения конкурса раскрывает MQ как *Modularity Quality*, не задавая
уравнение. Здесь полностью зафиксирована рабочая интерпретация Newman–Girvan;
её нельзя называть подтверждённой организаторами конвенцией. BasicMQ/TurboMQ
из литературы по программной модульности не подставляются вместо неё.

## Вырождения и сравнение

| Ситуация | Поведение |
|---|---|
| Пустые данные | Размеры 0, доля крупнейшей группы NaN, все метрики NaN |
| Одна группа или все группы singleton | SW/CH/S_Dbw/AVI/AVU NaN; `partition_status` отмечает вырождение |
| Тривиальное разбиение и непустая сеть | Q вычисляется, но статус `defined_trivial_partition`; Q=0 для одной группы не считается подтверждением качества |
| Нет рёбер | AVI/AVU/Q NaN, геометрические метрики считаются при допустимых признаках |
| Все признаки постоянны | SW/CH/S_Dbw NaN, сетевые метрики сохраняют свою отдельную область определения |
| Частичные singleton-группы | Не исключаются; возвращаются минимальный размер и доля крупнейшей группы |
| Неконечный численный результат | NaN со статусом, без назначения идеального балла |

Проверки включают ручные расчёты для двух треугольников с мостом и без,
взвешенного моста, трёх сообществ, изолята, вырожденной геометрии, двух вариантов
плотности S_Dbw и перестановки меток/строк. SW/CH сверяются со scikit-learn;
Q также сверяется с NetworkX, если библиотека присутствует в окружении.
Эти проверки удостоверяют расчёт выбранных формул. Они не подтверждают
экономический смысл, пространственную интерпретацию или устойчивость во времени.
