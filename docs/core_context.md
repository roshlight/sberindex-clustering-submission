# Муниципальный контекст 2024 года

Подготовлена таблица из **2 016 муниципалитетов**, точно совпадающих с исследовательской выборкой. Справочник покрывает все 2 016 ID, индекс доступности рынков — **2 004**. Остальные **12 значений сохранены как null**. Эта таблица предназначена для описательной проверки контекста групп в 2024 году и не меняет признаки или результаты исходного расчёта.

## Источники и единица наблюдения

Одна строка результата — один `territory_id`. Список ID получен через DISTINCT из `reports/initial_study/assignments.parquet`: 193 536 строк назначений содержат 2 016 уникальных ID. Повторения по месяцам и методам не создают дополнительные строки контекста. Это точная выборка завершённого исследования, а не полный перечень муниципалитетов России.

Первое левое соединение использует `reports/enrichment_v1/crosswalk/municipal_crosswalk_2024-01-01.csv`. Во входном справочнике 2 594 уникальных ID; 578 находятся вне исследовательской выборки. Второе левое соединение использует исходный `market_access.parquet` из архива организатора: 2 571 уникальный ID, из которых 567 находятся вне выборки. Оба соединения выполняются только по `territory_id`, с проверкой кардинальности `one_to_one`. Названия и коды ОКТМО не используются для подбора совпадений.

Оригинал показателя расположен относительно корня репозитория по пути `../../work/sberindex-research/hackathon-bundle/hackathonlicence/market_access.parquet`. Его происхождение, семантика и условия использования зафиксированы в [каталоге источников](../configs/source_catalog.json), запись `sber_market_access_2024`; исходное описание опубликовано [СберИндексом](https://sberindex.ru/ru/research/data-sense-opisanie-nabora-dannikh-khakatona-sberindeksa-po-munitsipalnim-dannim). Индекс описывает потенциальную доступность рынков, а не наблюдаемые торговые или транспортные потоки.

## Контракт результата

| Поле | Содержание |
|---|---|
| `territory_id` | Целочисленный ID из точной выборки исследования |
| `region` | `region_name` из справочника |
| `oktmo` | Исходный строковый код справочника с сохранением нулей и разделителей |
| `type` | `municipal_district_type` из справочника |
| `snapshot_date` | Дата состояния справочника `2024-01-01`, логический тип Parquet DATE |
| `market_access` | Число из исходного файла без пересчёта; null при отсутствии значения |
| `measurement_year` | `2024`, год статического индекса |

`snapshot_date` и `measurement_year` относятся к разным источникам. Они не означают, что показатель был опубликован или доступен аналитику 1 января 2024 года. Индекс не переносится в 2023 год и не размножается на месяцы; новое месячное наблюдение из него не возникает. Для дальнейшей экономической интерпретации остаются существенными датировка, смысл индекса и неполное покрытие.

## Проверки и пропуски

Скрипт отказывается от соединения при повторном ID справа, в том числе вне исследовательской выборки. Он также отклоняет пустые или некорректные ключи, смешанные даты справочника, неполное покрытие справочником, пустые обязательные атрибуты, нечисловые и бесконечные значения индекса. Число строк и точное множество ID проверяются после соединений. Входные файлы не изменяются; повторная запись в существующий выходной каталог запрещена.

| Проверка локального запуска | Результат |
|---|---:|
| Строк и уникальных ID в результате | 2 016 |
| ID, найденных в справочнике | 2 016 |
| ID с наблюдаемым `market_access` | 2 004 |
| ID без строки в источнике `market_access` | 12 |
| Найденных строк с пустым значением индекса | 0 |
| Заполненных или подставленных значений | 0 |

Отдельный CSV различает `source_row_absent` и `source_value_null`. В выполненном запуске все 12 пропусков имеют причину `source_row_absent`. Это техническое описание покрытия: оно само по себе не устанавливает экономическую причину отсутствия каждого муниципалитета в источнике. Нулевое наблюдаемое значение, если оно присутствует, сохраняется числом и не считается пропуском.

## Запуск и артефакты

Из корня репозитория:

```powershell
uv run --project enrichment --frozen python enrichment/scripts/prepare_core_context.py --assignments reports/initial_study/assignments.parquet --crosswalk reports/enrichment_v1/crosswalk/municipal_crosswalk_2024-01-01.csv --market-access ../../work/sberindex-research/hackathon-bundle/hackathonlicence/market_access.parquet --output enrichment/data/core-context-20260914-01 --expected-count 2016
```

Все входные пути, выходной каталог и ожидаемое число ID задаются CLI. Для повторного запуска нужен новый выходной каталог. На сервере следует передать фактические серверные пути; копировать локальную структуру `work/` не требуется.

Локальный запуск создал `enrichment/data/core-context-20260914-01/`:

- `municipal_context_2024.parquet` — контекст из 2 016 строк.
- `market_access_missing_ids.csv` — 12 ID с регионом, ОКТМО, типом и причиной пропуска.
- `core_context_manifest.json` — SHA256 трёх входов и двух выходных файлов, хеш скрипта, хеши `pyproject.toml` и `uv.lock`, версии Python/DuckDB/pandas, показатели покрытия и результаты QA.

Тесты проверяют сохранение точной выборки, различие нуля/null/отсутствующей строки, отказ при дублях справа, неполном справочнике, пустом ключе, неверной дате и неверном ожидаемом числе ID. Локально прошли 7 тестов и Ruff. Дополнительное чтение готового Parquet подтвердило 2 016 уникальных ID, 2 004 наблюдаемых значения и отсутствие потерь относительно DISTINCT исходных назначений.

Статус: **ready with conditions** — таблица пригодна как контекст 2024 года при сохранении пропусков и временных ограничений. Она не устанавливает причин группировки или переходов и не добавляет новую статистическую модель.
